## 1.1 项目定位

平台以社区版为底座，保留设备、凭证、遥测、规则引擎、仪表板和 REST API，并在独立服务 `thing-model` 中补充产品、TSL 物模型、产品资产和按产品规则链能力。

当前实现的主链路是：

```text
产品与 TSL 提交
  -> thing-model 校验并保存
  -> 调用中国中铁物联网平台 REST 同步设备配置、资产和规则链
  -> 设备通过中国中铁物联网平台 MQTT 接入
  -> 产品规则链校验遥测与事件
  -> 输出 Kafka 标准化消息
```

## 1.2 当前范围

| 范围 | 内容 |
| --- | --- |
| 本仓库实现 | `thing-model`、`ui-ngx` 产品页面和租户服务账号弹窗、TSL 转换脚本、模拟脚本 |
| 中国中铁物联网平台原生能力 | 租户、用户、MQTT 传输、设备、设备配置、资产、规则链、RPC、OTA、仪表板 |
| 外部依赖 | Kafka；TDengine 入湖由独立工程 `thingsboard-ingest` 负责，不在本仓库 |
| 尚未实现 | 组织树、项目/工点、设备台账、事件中心、开放 API、设备批量开通 API、OTA/SDK 封装、JT/T808/HTTPS/CoAP |

## 1.3 核心对象

| 对象 | 承载位置 | 说明 |
| --- | --- | --- |
| 厂商租户 | 中国中铁物联网平台租户 | 一个厂商一个租户，产品数据按租户隔离 |
| 产品 | `plat_product` | 产品 ID 全系统唯一，主键为 `(tenant_id, product_id)` |
| TSL 版本 | `plat_product_tsl` | 同一租户同一 产品 ID 下按 `version` 管理 |
| 设备模板 | 中国中铁物联网平台设备配置 | 由产品名称、型号和 TSL 摘要同步生成 |
| 产品资产 | 中国中铁物联网平台资产 | 保存 `tsl_json`、`tsl_schema`、属性/事件/行为数量等 `SERVER_SCOPE` 属性 |
| 产品规则链 | 中国中铁物联网平台规则链 | 名称等于 产品 ID，绑定到设备配置的 `defaultRuleChainId` |
| 设备 | 中国中铁物联网平台设备 | 由中国中铁物联网平台或运维脚本管理，`thing-model` 不提供设备开通 API |
| 厂商服务账号 | `plat_vendor_account` | 每个租户一个租户管理员，密码 AES-GCM 加密 |

## 1.4 已实现能力

- 产品与 TSL 版本管理，产品 ID 全系统唯一。
- TSL JSON Schema 结构校验与业务校验。
- 压缩 TSL schema 生成，并内嵌到产品规则链。
- 设备配置、产品资产、规则链同步和失败记录。
- 规则链运行时校验属性、事件、枚举、范围、必填、int32、报文大小和时间戳。
- Kafka 三个固定 主题：`iot.telemetry.normalized`、`iot.event.normalized`、`iot.invalid`。
- 产品列表、产品详情、TSL 编辑/校验/删除页面；保存物模型后自动同步。
- 删除产品前检查设备，删除时清理 TSL 和独占中国中铁物联网平台资源。
- 新建租户后自动创建并注册专用租户管理员服务账号。
- 腾讯 TSL 转换脚本、设备注册脚本、遥测/网关模拟脚本。
- `thing-model` 单元测试、Web Slice、Testcontainers 数据库测试和外部中国中铁物联网平台集成测试。
