## 3.1 TSL 结构

`thing-model` 使用 JSON Schema `thing-model/src/main/resources/schemas/tsl-v1.5.schema.json` 做结构校验，再用 `TslValidator` 做业务校验。完整的物模型定义规范见 [物模型定义规范使用手册](manuals/物模型定义规范使用手册.md)。

最小 TSL：

```json
{
  "version": "1.0",
  "profile": {
    "ProductId": "9HYN9PJNOY",
    "CategoryId": "1"
  },
  "properties": [
    {
      "id": "rssi",
      "name": "信号强度",
      "mode": "r",
      "define": {
        "type": "int",
        "min": -120,
        "max": 0,
        "unit": "dBm"
      }
    }
  ]
}
```

### 顶层字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `version` | 是 | TSL 版本，1~32 字符 |
| `profile` | 是 | 至少包含 产品 ID 或 `productId` |
| `properties` | 是 | 属性数组，可为空数组 |
| `events` | 否 | 事件数组 |
| `actions` | 否 | 行为数组 |

### 属性

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 标识符，同时作为遥测键 |
| `name` | 是 | 中文名，1~128 字符 |
| `desc` | 否 | 描述，最多 512 字符 |
| `mode` | 是 | `r` 或 `rw` |
| `required` | 否 | 运行时是否要求上报 |
| `define` | 是 | 数据类型和元数据 |
| `mapping` | 否 | 枚举映射，也兼容放在 `define.mapping` |

### 事件

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 事件标识，运行时报文中的 `event_id` |
| `name` | 是 | 中文名 |
| `type` | 是 | `info` / `alert` / `fault`，也兼容 `eventType` |
| `params` | 否 | 事件参数数组，也兼容 `output` |

### 行为

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 行为标识，运行时映射为 RPC 方法名 |
| `name` | 是 | 中文名 |
| `input` | 否 | 输入参数，也兼容 `inputParams` |
| `output` | 否 | 输出参数，也兼容 `outputParams` |

## 3.2 数据类型

| TSL 类型 | 运行时要求 | 说明 |
| --- | --- | --- |
| `bool` | boolean 或 0/1 | 规则链归一为 boolean |
| `int` | 32 位整数 | 超出 int32 报 `int32` |
| `float` | 有限数字 | 不强制整数 |
| `string` | 字符串 | 长度由 schema 限制 |
| `enum` | 整数且在映射内 | 映射键必须是数字 |
| `enum_string` | 字符串且在映射内 | 映射保留字符串键 |
| `timestamp` | 整数 | 小于 `1e12` 时按秒处理并乘 1000 |
| `struct` | JSON 对象 | 不允许嵌套结构 |

`define` 支持 `type`、`min`、`max`、`start`、`step`、`unit`、`mapping`、`specs`、`fields`。

## 3.3 业务校验规则

| 规则 | 结果 |
| --- | --- |
| 标识符格式 `^[A-Za-z_][A-Za-z0-9_]{0,49}$` | `ID_INVALID` |
| 属性、事件、行为、参数标识符重复 | `ID_DUP` / `EVENT_ID_DUP` / `ACTION_ID_DUP` / `PARAM_DUP` |
| 属性 + 事件 + 行为总数不能超过 100 | `FUNCTION_POINTS` |
| `min > max` | `RANGE_REVERSED` |
| `start` 不在 `min`/`max` 内 | `START_OUT_OF_RANGE` |
| `step < 0` | `STEP_INVALID` |
| `int` 的 `min` / `max` / `start` 超出 32 位 | `INT_RANGE` |
| `enum` / `enum_string` 的映射少于 2 项 | `ENUM_MAPPING` |
| `enum` 的映射键不是数字 | `ENUM_KEY` |
| 非枚举类型配置映射 | 警告 `MAPPING_NOT_ALLOWED` |
| 结构体字段为空 | `STRUCT_EMPTY` |
| 结构体嵌套结构体 | `STRUCT_NESTED` |
| 事件或行为参数使用结构体 | `STRUCT_NOT_ALLOWED` |
| 属性使用 `ts`、`event_id`、`event_type`、`event_ts` | 警告 `ID_RESERVED` |
| 非数值类型配置范围 | 警告 `METADATA_TYPE_MISMATCH` |

## 3.4 压缩 schema

发布产品时，`CompactSchema` 把 TSL 压缩后写入：

- 产品资产的 `tsl_schema` 属性；
- 产品规则链的校验脚本。

结构示例：

```json
{
  "schemaVersion": "1.0",
  "productId": "9HYN9PJNOY",
  "tslVersion": "1.0",
  "strictUnknown": false,
  "keys": {
    "rssi": {
      "t": "int",
      "min": -120.0,
      "max": 0.0,
      "unit": "dBm",
      "mode": "r"
    }
  },
  "events": {
    "alarm": {
      "type": "alert",
      "params": {
        "alarmType": {
          "t": "enum_string",
          "map": {
            "low_power": "低电量报警"
          }
        }
      }
    }
  }
}
```

规则链校验使用内嵌 schema，不依赖设备上的 `tsl_schema` 属性。旧脚本仍会为设备写入 `tsl_schema` 以兼容历史行为。

## 3.5 版本与状态

| 场景 | 行为 |
| --- | --- |
| `POST /api/products` | 校验 TSL，保存 DRAFT，同步成功后置 `PUBLISHED` |
| `PUT /api/products/{id}/thing-model` | 提交新版本并重新同步 |
| 同一版本、相同 checksum | 幂等复用已有记录并重新同步 |
| 同一版本、不同 checksum | `409 TSL_VERSION_EXISTS` |
| 同步失败 | 保留 DRAFT，记录 `sync_result`，返回 `502` |
| `POST /api/products/{id}/sync` | 重新同步最新版本 |
| `DEPRECATED` | 数据库枚举存在，当前没有弃用或回滚接口 |

当前没有独立的 `publish`、`deprecate`、`rollback` 接口。产品创建、物模型更新和重新同步都会直接触发中国中铁物联网平台同步。

## 3.6 目录接口

`GET /api/products/{productId}/catalog` 返回最新 TSL 的结构化目录：

```json
{
  "productId": "9HYN9PJNOY",
  "version": "1.0",
  "properties": [
    {
      "id": "rssi",
      "name": "信号强度",
      "dataType": "int",
      "mode": "r",
      "unit": "dBm",
      "min": -120.0,
      "max": 0.0,
      "step": null,
      "required": false,
      "mapping": null
    }
  ],
  "events": [],
  "actions": []
}
```

## 3.8 限制

- 没有可视化结构化 TSL 编辑器，前端通过 JSON 表单提交。
- 没有单独的历史版本回滚 UI。
- `DEPRECATED` 仅保留状态值，没有状态流转实现。
- 结构体运行时只校验是否为对象且不嵌套，不校验内部字段类型。
- 非严格模式下未知属性会被规则链丢弃并记入 `dropped`。
