# 5 设备接入

> 中国中铁物联网平台文档集｜[总目录](../README.md)｜上一篇 [产品同步与规则链](04-产品同步与规则链.md)｜下一篇 [前端与权限](06-前端与权限.md)

## 5.1 接入方式

设备直连中国中铁物联网平台内置 MQTT 传输，不使用外部消息代理，也不在平台侧转换 `$thing/*` 主题。协议差异由设备固件或设备侧 SDK 处理。

```text
设备 -> MQTT -> 中国中铁物联网平台 MQTT 传输
     -> 产品设备配置
     -> 产品规则链校验
     -> 中国中铁物联网平台遥测存储 + Kafka
```

平台当前只提供 MQTT 接入说明和模拟脚本，不提供设备批量开通 API、设备 SDK、OTA 服务或 RPC 业务封装。

## 5.2 连接参数

| 参数 | 值 |
| --- | --- |
| MQTT 版本 | 3.1.1，兼容 5.0 |
| 地址 | 由部署环境提供，例如平台域名或 `localhost:1883` |
| TLS | 生产建议 8883，当前测试环境是否启用由运维决定 |
| ClientId | 全局唯一，建议使用 DeviceName |
| 用户名 | 访问令牌 |
| 密码 | 空字符串 |
| 心跳间隔 | 60 秒 |
| 清理会话 | `true` |
| QoS | `1` |
| 最大重连间隔 | 30 秒，建议指数退避 |

设备采用**预创建**方式：先在中国中铁物联网平台创建设备、绑定产品设备配置、取得访问令牌，再连接平台。不要多台设备共用同一令牌。

## 5.3 设备主题

| 主题 | 方向 | 用途 |
| --- | --- | --- |
| `v1/devices/me/telemetry` | 上行 | 属性、事件、遥测 |
| `v1/devices/me/attributes` | 上行/下行 | 客户端属性和共享属性 |
| `v1/devices/me/attributes/request/{id}` | 上行 | 请求服务端属性 |
| `v1/devices/me/attributes/response/{id}` | 下行 | 服务端属性响应 |
| `v1/devices/me/rpc/request/{id}` | 下行 | 平台下发 RPC |
| `v1/devices/me/rpc/response/{id}` | 上行 | 设备返回 RPC 结果 |
| `v1/gateway/*` | 双向 | 网关代子设备接入 |

## 5.4 属性与遥测

属性上报与普通遥测走同一主题。设备可以使用扁平对象或带时间戳的 `values` 对象：

```json
{
  "imei": "860000000000001",
  "signalStrength": -65
}
```

```json
{
  "ts": 1793240957000,
  "values": {
    "imei": "860000000000001",
    "signalStrength": -65
  }
}
```

约定：

- 属性键名必须等于 TSL 的 `properties[].id`。
- 时间戳统一使用毫秒；小于 `1e12` 的秒级时间戳会被规则链乘 1000。
- 未上报的属性不会更新。
- 单条报文序列化后建议不超过 4096 字节，规则链会拒绝更大的报文。
- 当前规则链只校验遥测分支；`Post attributes` 分支直接保存客户端属性。

属性白名单只用于少量非时序数据：

| 键 | Scope | 用途 |
| --- | --- | --- |
| `tsl_version` | server | 物模型版本 |
| `tsl_schema` | server | 兼容旧规则链；当前校验使用内嵌 schema |
| `tenant_id` | server | 租户标识 |
| `device_uuid` | server | 设备标识 |
| `site_code` | server | 工点编码 |
| `product_id` | server | 产品标识 |
| `cfg_json` | shared | 远程配置 |
| `shadow_desired` / `shadow_reported` | shared / client | 影子期望与上报 |
| `fw_title` / `fw_version` / `fw_checksum` / `fw_size` | shared | OTA 固件信息 |

## 5.5 事件上报

事件与属性使用同一主题。支持单事件对象和 `events` 数组。

单事件：

```json
{
  "event_id": "refuelRecord",
  "event_type": "info",
  "event_ts": 1793240957000,
  "volume": 120.5,
  "percentage": 45.0,
  "tankId": 1
}
```

事件数组：

```json
{
  "events": [
    {
      "event_id": "alarm",
      "event_type": "alert",
      "event_ts": 1793240957000,
      "alarmType": "low_power",
      "remark": "设备电量低"
    }
  ]
}
```

约定：

- `event_id` 必须属于当前产品 TSL 的 `events[].id`。
- `event_type` 必须是 `info` / `alert` / `fault`，并与 TSL 定义一致。
- `event_ts` 使用毫秒；省略时使用平台接收时间。
- 同一包内 `events[].event_id` 必须一致，混合事件标记为 `events:mixed`。
- 事件参数与保留键同级，不要额外嵌套 `params`。
- 事件不进入中国中铁物联网平台告警，由规则链投递到 `iot.event.normalized`。

## 5.6 RPC 与行为

平台到设备的 RPC 使用：

```text
v1/devices/me/rpc/request/{requestId}
```

设备返回：

```text
v1/devices/me/rpc/response/{requestId}
```

属性写入使用通用方法：

```json
{
  "method": "set",
  "params": {
    "reportInterval": 60
  }
}
```

行为调用使用 TSL 的 `actions[].id` 作为 `method`。设备应在规则链 RPC 节点超时前返回结果；当前 RPC 节点超时为 60 秒。关键操作建议设备执行后额外上报状态遥测，不要只依赖 RPC 回执。

## 5.7 网关接入

网关设备使用自己的访问令牌连接 MQTT，并开启网关模式：

```json
{
  "additionalInfo": {
    "gateway": true
  }
}
```

常用主题：

| 主题 | 用途 |
| --- | --- |
| `v1/gateway/connect` | 子设备上线 |
| `v1/gateway/disconnect` | 子设备下线 |
| `v1/gateway/telemetry` | 子设备遥测与事件 |
| `v1/gateway/attributes` | 子设备属性 |
| `v1/gateway/rpc` | 子设备 RPC |

数组和事件规则与直连设备一致。生产环境建议预创建子设备，确保 `site_code`、`tsl_version` 等属性完整。

## 5.8 设备注册与模拟脚本

脚本位于 `tools/src/main/python/`。

注册设备：

```powershell
python tools/src/main/python/register_devices.py `
  --product-id 4DZDCQUA2D `
  --prefix 4DZDCQUA2D --count 10 `
  --site-code SIM `
  --output device-credentials.csv `
  --password tenant
```

脚本会按产品设备配置创建设备，写入服务端属性，并导出访问令牌 CSV。CSV 含明文令牌，禁止提交到仓库。

直连遥测模拟：

```powershell
python tools/src/main/python/simulate_telemetry.py `
  --product-id 4DZDCQUA2D `
  --tsl thing-model/migrate/4DZDCQUA2D.tsl.json `
  --mode mixed --count 10 --interval 1
```

网关模拟：

```powershell
python tools/src/main/python/simulate_gateway.py `
  --gateway-csv gateway-credentials.csv `
  --gateway-name gateway-01 `
  --sub-devices-csv sub-devices.csv `
  --product-id 4DZDCQUA2D `
  --mode mixed --count 2 --interval 1
```

详细参数见 `tools/src/main/python/README.md`。

## 5.10 错误与限制

- 中国中铁物联网平台不会为每条 MQTT 消息返回业务错误码。QoS 确认只表示消息到达，不代表校验通过。
- 非法数据不写时序库，规则链将其投递到 `iot.invalid`。
- 平台不缓存离线消息，断网数据需设备本地缓存后补传，并保留原始时间戳。
- 事件幂等由下游处理；建议设备重传时保持 `event_ts` 不变。
- 中国中铁物联网平台原生支持 OTA、共享属性和 RPC，但 `thing-model` 没有实现这些能力的业务封装。
