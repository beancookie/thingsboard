# 10 租户与产品快速使用手册

> 中铁信科物联网平台文档集｜[总目录](../README.md)｜上一篇 [迁移测试与路线图](09-迁移测试与路线图.md)｜下一篇 [AI Agent 对话助手方案](11-AI-Agent对话助手方案.md)

本文用于从零创建一个厂商租户，并使用示例物模型创建第一个产品。

示例物模型文件：

```text
thing-model/migrate/4DZDCQUA2D.json
```

平台会自动识别腾讯格式并转换为规范 TSL，不需要先执行转换器。

## 10.1 适用角色

| 角色 | 用途 |
| --- | --- |
| 平台管理员 `SYS_ADMIN` | 创建租户、初始化服务账号、创建租户管理员 |
| 厂商管理员 `TENANT_ADMIN` | 登录平台、创建产品和物模型 |

## 10.2 前置条件

- `thing-model` 已启动，并且配置了有效的 `THINGMODEL_SECRET_KEY`。
- 平台管理员可以登录系统。
- 示例物模型使用版本 `1.0`，ProductId 为 `4DZDCQUA2D`。

## 10.3 创建租户

1. 使用 `SYS_ADMIN` 登录。
2. 进入“租户”页面。
3. 点击“新增租户”。
4. 填写租户名称等必填信息，点击保存。
5. 保存成功后会自动弹出“初始化厂商服务账号”窗口。
6. 等待提示初始化成功，不需要输入用户名或密码。

系统会自动创建类似下面的服务账号：

```text
thing-model-svc-<tenantId>@thing-model.local
```

该账号用于平台同步 ThingsBoard 资源，不是日常登录账号。

## 10.4 创建可登录的租户管理员

1. 在租户列表找到刚创建的租户。
2. 点击“管理租户管理员”。
3. 新增一个用户，角色选择“租户管理员”。
4. 设置邮箱和密码并保存。
5. 不要删除自动创建的服务账号。

## 10.5 租户管理员登录

1. 退出平台管理员账号。
2. 使用刚创建的租户管理员账号登录。
3. 确认左侧菜单出现“产品”。

如果没有“产品”菜单，请检查当前用户角色是否为租户管理员。

## 10.6 新建产品

1. 进入“产品”页面。
2. 点击“新建产品”。
3. 按下表填写：

| 字段 | 示例值 |
| --- | --- |
| 产品 ID | `4DZDCQUA2D` |
| 名称 | `挖掘机物模型` |
| 型号 | `4DZDCQUA2D` |
| 分类 | `1` |
| TSL 版本 | `1.0` |
| 严格未知字段 | 关闭 |
| 物模型 | 导入 `thing-model/migrate/4DZDCQUA2D.json` |

导入方式：

- 点击“导入 JSON”，选择腾讯原始文件 `4DZDCQUA2D.json`；
- 平台会自动转换 `stringenum`、`dataType` 和 struct `specs` 格式；
- 也可以使用已经转换好的 `4DZDCQUA2D.tsl.json`。

## 10.7 校验并保存

1. 点击“校验”。
2. 校验通过后点击“保存”。
3. 保存后平台会自动同步 ThingsBoard，不需要手动点击同步按钮。

如果校验失败，页面会列出具体错误，按提示修改 TSL 后再次校验。

## 10.8 检查结果

保存成功后：

- 产品状态显示为“已发布”。
- 产品包含 3 个属性：
  - `deviceInfo`
  - `locationInfo`
  - `realStateInfo`
- 包含 4 个事件：
  - `refuelRecord`
  - `workRecord`
  - `fuelRecord`
  - `alarm`
- 行为数量为 0。
- 产品详情页可以查看：
  - 设备配置
  - 产品资产
  - 规则引擎

## 10.9 导入物模型后自动生成的数据

点击“保存”后，平台会校验 TSL，并按以下顺序生成或更新数据。

| 数据 | 是否自动生成 | 名称或内容 |
| --- | --- | --- |
| 平台产品记录 | 是 | `plat_product`，按 `(tenant_id, product_id)` 保存 |
| TSL 版本 | 是 | `plat_product_tsl`，保存 TSL 原文、版本和状态 |
| 属性/事件/行为目录 | 是 | `plat_tsl_property`、`plat_tsl_event`、`plat_tsl_action` |
| 规则引擎 | 是 | 名称为 ProductId，例如 `4DZDCQUA2D` |
| 设备配置 | 是 | 名称为“产品名称 + 型号”，绑定上一步生成的规则引擎 |
| 资产 | 是 | 名称为 `产品 <ProductId>`，类型为 `product` |
| 资产属性 | 是 | 写入 `tsl_json`、`tsl_schema`、属性/事件/行为数量等 |
| 产品绑定记录 | 是 | `plat_profile_binding`，记录设备配置、资产、规则引擎 ID |

### 不会自动生成的数据

| 数据 | 说明 |
| --- | --- |
| 资产配置 | 使用 ThingsBoard 已有的默认资产配置，不会为产品单独创建 |
| 设备 | 不会自动创建设备实例，需要后续手动创建或通过脚本注册 |
| Kafka topic | 规则引擎只引用配置的 topic，不会自动创建 Kafka topic |
| 租户服务账号 | 在创建租户时初始化，不在导入物模型时生成 |

> 如果 ThingsBoard 没有配置默认资产配置，产品同步会失败。此时需要先在 ThingsBoard 中配置默认资产配置。

自动生成完成后，产品详情页的“设备配置”“产品资产”“规则引擎”三个入口应可以正常打开。

## 10.10 常见问题

| 问题 | 处理 |
| --- | --- |
| 自动初始化服务账号失败 | 检查 `THINGMODEL_SECRET_KEY` 是否已配置，且 Base64 解码后为 16/24/32 字节 |
| 没有“产品”菜单 | 确认当前用户角色是租户管理员 |
| TSL 校验失败 | 根据页面错误列表修正属性、事件或行为定义 |
| 产品 ID 已存在 | ProductId 在全系统唯一，不同租户也不能重复 |
| 设备无法接入 | 先在产品详情确认设备配置和规则引擎已生成 |

示例物模型只用于演示导入流程。实际厂商接入时，请使用该厂商自己的 TSL。
