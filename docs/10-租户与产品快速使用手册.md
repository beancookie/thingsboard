# 10 租户与产品快速使用手册

> 中国中铁物联网平台文档集｜[总目录](../README.md)｜上一篇 [测试与路线图](09-测试与路线图.md)｜下一篇 [AI Agent 对话助手方案](11-AI-Agent对话助手方案.md)

本文用于从零创建一个租户，并使用标准示例物模型创建第一个产品。

标准示例物模型：

```text
docs/manuals/examples/standard-thing-model.tsl.json
```

示例产品 ID 为 `DEMO_TSL_001`，平台会自动识别并处理兼容格式的物模型。

## 10.1 适用角色

| 角色 | 用途 |
| --- | --- |
| 系统管理员 | 创建租户、初始化平台服务账号、创建租户管理员 |
| 租户管理员 | 登录平台、创建产品和物模型 |

## 10.2 前置条件

- 平台服务已启动，并完成基础配置。
- 系统管理员可以登录平台。
- 标准示例物模型版本为 `1.0`，产品 ID 为 `DEMO_TSL_001`。

## 10.3 创建租户

1. 使用系统管理员登录。
2. 进入“租户”页面。
3. 点击“新增租户”。
4. 填写租户名称等必填信息，点击保存。
5. 保存成功后会自动执行平台服务账号初始化。
6. 等待提示初始化成功，不需要输入用户名或密码。

平台服务账号由系统自动管理，不需要日常登录。

## 10.4 创建可登录的租户管理员

1. 在租户列表找到刚创建的租户。
2. 点击“管理租户管理员”。
3. 新增一个用户，角色选择“租户管理员”。
4. 设置邮箱和密码并保存。
5. 不要删除自动创建的平台服务账号。

## 10.5 租户管理员登录

1. 退出系统管理员账号。
2. 使用刚创建的租户管理员账号登录。
3. 确认左侧菜单出现“产品”。

如果没有“产品”菜单，请检查当前用户角色是否为租户管理员。

## 10.6 新建产品

1. 进入“产品”页面。
2. 点击“新建产品”。
3. 按下表填写：

| 字段 | 示例值 |
| --- | --- |
| 产品 ID | `DEMO_TSL_001` |
| 名称 | 标准环境监测设备 |
| 型号 | `DEMO-ENV-01` |
| 分类 | `1` |
| TSL 版本 | `1.0` |
| 严格未知字段 | 关闭 |
| 物模型 | 导入 `docs/manuals/examples/standard-thing-model.tsl.json` |

导入方式：

- 点击“导入 JSON”，选择标准示例物模型文件；
- 平台会自动处理兼容格式的枚举、数据类型和结构体写法。

## 10.7 校验并保存

1. 点击“校验”。
2. 校验通过后点击“保存”。
3. 保存后平台自动生效，不需要额外操作。

如果校验失败，页面会列出具体错误，按提示修改 TSL 后再次校验。

## 10.8 检查结果

保存成功后：

- 产品状态显示为“已发布”。
- 产品包含 7 个属性：
  - `temperature`
  - `humidity`
  - `mode`
  - `reportInterval`
  - `alarmThreshold`
  - `relay`
  - `deviceInfo`
- 包含 2 个事件：
  - `overTemperature`
  - `deviceFault`
- 包含 3 个行为：
  - `setMode`
  - `setRelay`
  - `applyConfig`
- 产品详情页可以查看：
  - 产品配置
  - 产品资产
  - 规则引擎

## 10.9 保存后自动生成的数据

点击“保存”后，平台会校验 TSL，并生成或更新以下数据。

| 数据 | 是否自动生成 | 名称或内容 |
| --- | --- | --- |
| 平台产品记录 | 是 | `plat_product`，按 `(tenant_id, product_id)` 保存 |
| TSL 版本 | 是 | `plat_product_tsl`，保存 TSL 原文、版本和状态 |
| 属性/事件/行为目录 | 是 | `plat_tsl_property`、`plat_tsl_event`、`plat_tsl_action` |
| 规则引擎 | 是 | 名称为 产品 ID，例如 `DEMO_TSL_001` |
| 产品配置 | 是 | 名称为“产品名称 + 型号”，绑定上一步生成的规则引擎 |
| 资产 | 是 | 名称为 产品 <产品 ID>，类型为 `product` |
| 资产属性 | 是 | 写入 `tsl_json`、`tsl_schema`、属性/事件/行为数量等 |
| 产品绑定记录 | 是 | `plat_profile_binding`，记录产品配置、资产、规则引擎 ID |

### 不会自动生成的数据

| 数据 | 说明 |
| --- | --- |
| 资产配置 | 使用平台已有的默认资产配置，不会为产品单独创建 |
| 设备 | 不会自动创建设备实例，需要后续手动创建或通过脚本注册 |
| Kafka 主题 | 规则引擎只引用配置的主题，不会自动创建 Kafka 主题 |
| 平台服务账号 | 在创建租户时初始化，不在保存物模型时生成 |

> 如果平台没有配置默认资产配置，产品发布会失败。此时需要先配置默认资产配置。

自动生成完成后，产品详情页的“产品配置”“产品资产”“规则引擎”三个入口应可以正常打开。

## 10.10 常见问题

| 问题 | 处理 |
| --- | --- |
| 平台初始化失败 | 检查平台服务配置和日志后重试 |
| 没有“产品”菜单 | 确认当前用户角色是租户管理员 |
| TSL 校验失败 | 根据页面错误列表修正属性、事件或行为定义 |
| 产品 ID 已存在 | 产品 ID 在全系统唯一，不同租户也不能重复 |
| 设备无法接入 | 先在产品详情确认产品配置和规则引擎已生成 |

示例物模型只用于演示导入流程。实际厂商接入时，请使用该厂商自己的 TSL。
