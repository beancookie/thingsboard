## 9.1 腾讯 TSL 转换

转换器：

```text
thing-model/migrate/convert_tencent_tsl.py
```

单文件转换：

```powershell
python thing-model/migrate/convert_tencent_tsl.py `
  thing-model/migrate/4DZDCQUA2D.json `
  -o thing-model/migrate/4DZDCQUA2D.tsl.json
```

批量转换：

```powershell
python thing-model/migrate/convert_tencent_tsl.py `
  thing-model/migrate `
  --output-dir thing-model/migrate/converted
```

转换规则：

- 数值字符串转数字，例如 `"0.01"` -> `0.01`。
- `stringenum` 转 `enum_string`。
- `struct.specs` 数组转对象。
- `dataType` 转 `type`。
- 默认丢弃字符串类型的 `min` / `max` / `start` / `step`。
- 保留 `enum` / `enum_string` 的 mapping。
- 保留 struct 内 bool 的 mapping。
- 事件参数 `define` 同步转换。
- 默认不覆盖输入文件。
- `--flatten-structs` 使用下划线拼接字段，例如 `deviceInfo.company` -> `deviceInfo_company`。

转换后通过接口校验：

```http
POST /api/products/4DZDCQUA2D/thing-model/validate
X-Authorization: Bearer <TENANT_ADMIN_JWT>
Content-Type: application/json

{"tsl": <converted-tsl>}
```

转换器测试：

```powershell
python thing-model/migrate/test_convert_tencent_tsl.py
```

## 9.2 设备注册与数据模拟

脚本目录：

```text
thing-model/scripts/
```

| 脚本 | 用途 |
| --- | --- |
| `register_devices.py` | 按产品 Device Profile 注册设备，写入 server 属性，导出 Access Token CSV |
| `simulate_telemetry.py` | 直连设备遥测、事件、非法数据模拟 |
| `simulate_gateway.py` | 网关代子设备上报 |
| `test_rulechain_validation.js` | 不启动 ThingsBoard，直接测试规则链校验脚本 |

安装依赖：

```powershell
python -m pip install -r thing-model/scripts/requirements.txt
```

直连模拟：

```powershell
python thing-model/scripts/simulate_telemetry.py `
  --product-id 4DZDCQUA2D `
  --tsl thing-model/migrate/4DZDCQUA2D.tsl.json `
  --mode mixed --count 10 --interval 1
```

注册设备：

```powershell
python thing-model/scripts/register_devices.py `
  --product-id 4DZDCQUA2D `
  --prefix 4DZDCQUA2D --count 10 `
  --site-code SIM `
  --output device-credentials.csv `
  --password tenant
```

网关模拟：

```powershell
python thing-model/scripts/simulate_gateway.py `
  --gateway-csv gateway-credentials.csv `
  --gateway-name gateway-01 `
  --sub-devices-csv sub-devices.csv `
  --product-id 4DZDCQUA2D `
  --mode mixed --count 2 --interval 1
```

脚本说明见 `thing-model/scripts/README.md`。CSV 中含明文 Access Token，禁止提交到仓库。

## 9.3 测试

### 单元测试与 Web Slice

```bash
mvn -f thing-model/pom.xml test "-Dtest=!*IntegrationTest"
```

不依赖 Docker 和 ThingsBoard。

### 数据库集成测试

```bash
mvn -f thing-model/pom.xml test -Dtest=RepositoryIntegrationTest
```

使用 Testcontainers PostgreSQL。

### 外部 ThingsBoard 集成测试

```bash
mvn -f thing-model/pom.xml test -Dtest=ProductRuleChainTbIntegrationTest
```

默认连接：

```text
http://localhost:18080
tenant@thingsboard.org / tenant
sysadmin@thingsboard.org / sysadmin
```

可通过 `TB_URL`、`TB_USERNAME`、`TB_PASSWORD`、`TB_SYSADMIN_USERNAME`、`TB_SYSADMIN_PASSWORD` 覆盖。该测试需要 ThingsBoard 和 Docker。

### 全量测试

```bash
mvn -f thing-model/pom.xml test
```

全量测试默认包含外部 ThingsBoard 集成测试。

### 规则链脚本测试

```powershell
node thing-model/scripts/test_rulechain_validation.js
```

覆盖合法遥测、类型错误、越界、int32、报文超限、未知字段、枚举、时间戳、事件和事件数组。

### 前端验证

```bash
cd ui-ngx
yarn lint
yarn build:prod
```

## 9.6 外部入湖工程

本仓库只负责：

- 产品与 TSL；
- 规则链生成和绑定；
- 规则链校验；
- Kafka 三个 topic 的消息格式。

`thingsboard-ingest` 负责：

- 消费 `iot.telemetry.normalized` 和 `iot.event.normalized`；
- 按产品创建 TDengine 超级表、按设备创建子表；
- 写入遥测、事件和 DLQ；
- 指标与查询。

两边的契约见 [04-产品同步与规则链](04-产品同步与规则链.md) 的 Kafka 消息章节。入湖工程不在本仓库，本文不描述其内部实现。

## 9.7 已知限制

- 同步在 HTTP 请求内完成，没有异步任务和自动补偿。
- 规则链校验使用内嵌 schema，TSL 更新后必须重新同步才能刷新。
- 产品列表没有服务端分页。
- 没有产品弃用和回滚接口，`DEPRECATED` 只是数据库状态值。
- 设备侧业务错误码不由 ThingsBoard 返回，非法数据通过 `iot.invalid` 排查。
- 自动初始化服务账号依赖 ThingsBoard 激活接口和合法邮箱域名。
- 当前文档只描述代码中已实现的能力，未实现内容统一放在本文路线图。
