>
> 适用对象：系统管理员、租户管理员、平台运维人员

## 1. 文档说明

### 1.1 适用对象

- 平台系统管理员
- 租户管理员
- 负责 AI 助手配置和排障的运维人员

### 1.2 权限要求

- AI 助手仅对系统管理员和租户管理员显示。
- 客户用户看不到 AI 助手入口。
- 查询类操作按当前账号权限执行。
- 创建类操作必须经过用户确认后才执行。
- 服务端会再次校验角色、租户和数据范围。

### 1.3 前置条件

- AI Agent 服务已启动。
- 前端已将 `/api/ai-agent/` 转发到 AI Agent 服务。
- AI Agent 已配置 OpenAI 兼容模型。
- AI Agent 已配置物联网平台和 `thing-model` 服务地址。
- 当前用户已登录平台。

## 2. AI Agent 是什么

AI Agent 是平台内置的 AI 助手，通过对话帮助用户查询和创建平台资源。

它由三部分组成：

| 组成 | 说明 |
| --- | --- |
| 前端 AI 助手 | 页面右下角的悬浮按钮和对话面板 |
| AI Agent 服务 | 独立 Python 服务，负责对话、工具规划和动作执行 |
| 平台接口 | 通过 REST 调用物联网平台和 `thing-model` |

### 2.1 能做什么

- 查询租户
- 查询产品
- 查询设备
- 创建租户
- 创建租户管理员
- 创建产品
- 创建设备
- 创建用户

### 2.2 不能做什么

- 不能删除数据
- 不能修改数据
- 不能批量操作
- 不能跨租户操作
- 不能读取密码、JWT 或数据库密钥
- 不能在未确认的情况下执行创建操作

### 2.3 基本流程

```text
登录平台
  -> 打开 AI 助手
  -> 输入需求
  -> AI 返回回复或待确认操作
  -> 查看操作参数
  -> 确认执行或取消
  -> 查看执行结果
```

## 3. 页面入口

### 3.1 打开 AI 助手

1. 使用系统管理员或租户管理员登录平台。
2. 页面右下角显示 AI 助手悬浮按钮。
3. 点击悬浮按钮打开对话面板。
4. 可以拖动按钮调整位置。
5. 点击关闭按钮收起面板。

> 截图占位：`images/ai-agent/02-panel.png`

### 3.2 对话面板

对话面板包含：

- 标题
- 清空对话按钮
- 关闭按钮
- 对话消息区
- 待确认操作区
- TSL 附件区
- 输入框
- 上传 TSL、粘贴 TSL、发送按钮

### 3.3 清空对话

点击「清空对话」会清除：

- 当前对话消息
- 待确认操作
- 已附加的 TSL
- 输入框内容

清空后无法恢复。

> 截图占位：`images/ai-agent/07-clear-chat.png`

### 3.4 会话恢复

AI 助手会把当前账号的对话保存在浏览器本地。

- 刷新页面后可以恢复最近对话。
- 待确认操作也会恢复。
- 清除浏览器数据后会话丢失。
- 不同账号的会话相互隔离。

## 4. 使用流程

### 4.1 查询类操作

查询类操作会直接执行并返回结果，不需要确认。

示例：

```text
查询平台租户列表
查询当前租户的产品
查询当前租户的设备
```

### 4.2 创建类操作

创建类操作会先生成待确认操作，不会立即执行。

1. 输入创建需求。
2. AI 返回回复和待确认操作。
3. 查看操作名称和参数。
4. 点击「确认执行」。
5. 查看执行结果。
6. 如果参数有误，点击「取消」。

> 截图占位：`images/ai-agent/04-pending-actions.png`
>
> 截图占位：`images/ai-agent/05-confirm-result.png`

### 4.3 待确认操作区

待确认操作会显示：

- 操作名称
- 操作类型
- 参数 JSON

确认前请重点检查：

- 租户 ID
- 产品 ID
- 设备名称
- 用户邮箱
- 用户角色

### 4.4 取消操作

点击「取消」只会清除待确认操作，不会调用平台接口。

### 4.5 执行结果

执行完成后，助手会显示：

- 成功或失败
- 返回消息
- 返回数据

失败时请根据错误信息检查权限、参数、服务状态和资源是否已存在。

> 截图占位：`images/ai-agent/08-error.png`

## 6. 支持的创建操作

### 6.1 创建租户

仅系统管理员可用。

示例：

```text
创建一个租户，名称是测试厂商
```

创建后平台会初始化厂商服务账号。

### 6.2 创建租户管理员

仅系统管理员可用。

示例：

```text
为租户 <租户ID> 创建租户管理员，邮箱是 admin@example.com
```

租户管理员会收到激活邮件。

### 6.3 创建产品

租户管理员可用。

创建产品前需要先附加 TSL。

示例：

```text
使用当前 TSL 创建产品，产品 ID 是 TEST001，名称是测试产品
```

> 截图占位：`images/ai-agent/10-create-product.png`

### 6.4 创建设备

租户管理员可用。

设备会绑定产品配置。

示例：

```text
在 TEST001 产品下创建设备 device_001，中文名是测试设备
```

设备名称只能包含英文、数字和下划线，最长 48 个字符。

> 截图占位：`images/ai-agent/11-create-device.png`

### 6.5 创建用户

系统管理员和租户管理员可用。

示例：

```text
在当前租户创建客户用户，邮箱是 user@example.com
```

系统管理员创建用户时必须提供租户 ID。

> 截图占位：`images/ai-agent/12-create-user.png`

## 7. 使用 TSL 创建产品

### 7.1 上传 TSL 文件

1. 打开 AI 助手。
2. 点击回形针按钮。
3. 选择 JSON 文件。
4. 文件会显示在 TSL 附件区。
5. 输入创建产品需求并发送。

### 7.2 粘贴 TSL

1. 点击 TSL 按钮。
2. 在文本框中粘贴 TSL JSON。
3. 点击「应用 TSL」。
4. 确认附件区显示 TSL 文件。
5. 输入创建产品需求。

> 截图占位：`images/ai-agent/06-tsl-upload.png`

### 7.3 TSL 限制

- TSL 必须是 JSON 对象。
- 文件不能超过 2MB。
- TSL 格式错误时无法应用。
- 创建产品成功后 TSL 会自动移除。
- 可以点击「移除 TSL」取消附件。

## 8. 权限与安全

### 8.1 角色范围

| 角色 | 可用能力 |
| --- | --- |
| 系统管理员 | 查询租户、创建租户、创建租户管理员、创建用户 |
| 租户管理员 | 查询本租户产品、查询本租户设备、创建产品、创建设备、创建用户 |
| 客户用户 | 不显示 AI 助手 |

### 8.2 租户隔离

- 租户管理员只能操作 JWT 所属租户。
- 系统管理员代建产品或设备暂不支持。
- 跨租户操作会被拒绝。

### 8.3 写操作确认

- 写操作只生成待确认动作。
- 用户确认后才执行。
- 执行前服务端会重新校验权限和参数。
- 不能信任模型生成的 ID、名称或 TSL。

### 8.4 敏感信息

AI 助手不会：

- 索取密码
- 索取 JWT
- 读取数据库密码
- 读取 `THINGMODEL_SECRET_KEY`
- 在对话中返回设备访问令牌

### 8.5 服务端要求

- `AI_AGENT_OPENAI_API_KEY` 只能保存在后端 Secret 中。
- 不记录 JWT、密码、API 密钥 和完整敏感参数。
- 建议为 AI Agent 配置独立服务账号和最小权限。

## 9. 管理员配置

### 9.1 必要配置

```text
AI_AGENT_ENABLED=true
AI_AGENT_OPENAI_BASE_URL=https://api.deepseek.com/v1
AI_AGENT_OPENAI_API_KEY=<后端保存的密钥>
AI_AGENT_OPENAI_MODEL=deepseek-chat
AI_AGENT_THING_MODEL_URL=http://thing-model:8090
AI_AGENT_THINGSBOARD_URL=http://thingsboard:8080
```

### 9.2 上下文配置

```text
AI_AGENT_MAX_MESSAGES=20
AI_AGENT_MAX_ACTIONS=10
AI_AGENT_MAX_TSL_BYTES=2000000
```

- 最多保留最近 20 条对话消息。
- 最多保留最近 10 个待确认或执行动作。
- 超出上限时静默丢弃最早的内容。
- 系统提示词始终保留。

### 9.3 健康检查

```text
GET /health
GET /ready
```

### 9.4 前端代理

前端需要把 `/api/ai-agent/` 转发到 AI Agent 服务：

```text
/api/ai-agent/ -> http://ai-agent:8000/
```

## 10. 常见问题

| 问题 | 排查 |
| --- | --- |
| 看不到 AI 助手按钮 | AI 助手仅对系统管理员和租户管理员显示 |
| AI 助手没有响应 | 检查 AI Agent 服务、模型配置、网络和 API 密钥 |
| 一直显示正在思考 | 检查模型接口是否超时，稍后重试 |
| 没有生成待确认操作 | 可能是查询类操作，或需求不够明确 |
| 创建操作没有执行 | 需要点击「确认执行」，取消不会调用接口 |
| 创建租户失败 | 检查租户名称、权限和厂商服务账号初始化 |
| 创建租户管理员失败 | 需要系统管理员权限，并检查租户 ID和邮箱 |
| 创建产品失败 | 检查 TSL 是否附加、产品 ID 是否重复、服务账号是否可用 |
| 创建设备失败 | 检查产品是否存在、设备名称格式和产品配置是否已生成 |
| 创建用户失败 | 检查邮箱、角色、租户 ID和激活邮件配置 |
| 客户用户看不到 AI 助手 | 这是权限限制 |
| 执行结果提示无权限 | 检查当前账号角色和租户范围 |
| 对话历史丢失 | 清除浏览器数据会丢失本地会话 |
| TSL 无法应用 | 检查 JSON 格式和文件大小是否超过 2MB |
| AI 生成了错误参数 | 取消操作，补充更明确的需求后重新发送 |

## 11. API 地址

### 11.1 前端调用地址

```text
POST /api/ai-agent/chat
```

### 11.2 AI Agent 服务地址

```text
POST /chat
GET  /health
GET  /ready
```

### 11.3 请求示例

```json
{
  "mode": "chat",
  "messages": [
    {
      "role": "user",
      "content": "创建一个租户，名称是测试厂商"
    }
  ]
}
```

### 11.4 确认执行示例

```json
{
  "mode": "execute",
  "messages": [],
  "actions": [
    {
      "id": "call_xxx",
      "type": "create_tenant",
      "summary": "创建租户",
      "params": {
        "title": "测试厂商"
      },
      "status": "PROPOSED"
    }
  ]
}
```

### 11.5 依赖的平台接口

```text
GET  /api/auth/user
GET  /api/tenant
POST /api/tenant
POST /api/user?sendActivationMail=true
POST /api/device
POST /api/plugins/telemetry/DEVICE/{deviceId}/attributes/SERVER_SCOPE
GET  /api/products
POST /api/products
POST /api/admin/tenants/{tenantId}/provision-auto
```

### 11.6 错误码

| HTTP 状态 | 含义 |
| --- | --- |
| 400 | 请求参数错误或 TSL 无效 |
| 401 | 未认证或 JWT 无效 |
| 403 | 当前角色无权限 |
| 404 | 资源不存在 |
| 409 | 资源已存在或名称冲突 |
| 502 | 模型或平台服务不可用 |
| 500 | AI Agent 内部错误 |
