# 网关功能使用手册

> 中国中铁物联网平台文档集
>
> 适用对象：第三方网关硬件厂商、第三方设备接入集成商、平台联调人员

## 1. 文档说明

### 1.1 适用对象

- 第三方网关硬件厂商
- 第三方设备接入集成商
- 负责平台侧开通和联调的运维人员

### 1.2 权限要求

- 平台账号需要租户管理员权限。
- 平台侧开通操作可以通过平台页面完成，也可以通过 REST API 完成。
- 网关与子设备的数据上报使用 MQTT。

### 1.3 接入流程总览

```text
1. 登录平台
2. 查询或创建产品配置
3. 创建网关设备
4. 获取网关访问令牌
5. 创建子设备
6. 设置子设备属性（可选）
7. 建立网关-子设备关系（Contains）
8. 网关通过 MQTT 连接平台
9. 上报子设备遥测、属性、事件
10. 验证在线状态和遥测
```

> 截图占位：`images/gateway/00-integration-flow.png`

### 1.4 认证方式

除登录接口外，所有 REST API 都需要携带 JWT：

```http
X-Authorization: Bearer <JWT>
```

获取 JWT：

```text
POST /api/auth/login
```

刷新 JWT：

```text
POST /api/auth/token
```

> 请求体和响应字段以平台 Swagger 页面 `/swagger-ui.html` 为准。

### 1.5 平台管理员准备

在第三方接入前，平台管理员需确认：

- 网关仪表板 的网关设备页签使用关系类型 `Contains`。
- 网关仪表板 的状态卡使用平台标准字段。
- 网关 MQTT 地址和端口已对第三方网络开放。

第三方接入方在建立网关与子设备关系时，统一使用 `Contains`。

## 2. 产品配置

### 2.1 说明

每个子设备必须绑定产品配置。接入方可以：

- 查询平台已有的产品配置。
- 或自行创建基础产品配置。

### 2.2 页面操作

1. 使用租户管理员账号登录平台。
2. 进入「产品配置」页面。
3. 查看已有产品配置列表。
4. 如需新建，点击「新增产品配置」。
5. 填写名称、类型，传输方式选择 `DEFAULT`。
6. 保存并记录产品配置 ID。

> 截图占位：`images/gateway/01-device-profile-list.png`
>
> 截图占位：`images/gateway/02-create-device-profile.png`

### 2.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/deviceProfiles?pageSize=100&page=0` | 查询产品配置列表 |
| GET | `/api/deviceProfile/{deviceProfileId}` | 查询产品配置详情 |
| POST | `/api/deviceProfile` | 创建产品配置 |

> 请求体字段以平台 Swagger 页面 `/swagger-ui.html` 为准。

## 3. 创建网关设备

### 3.1 说明

网关是带有网关标记的普通设备。创建时必须开启网关模式，否则 MQTT 网关主题不可用。

### 3.2 页面操作

1. 进入「设备」页面。
2. 点击「新增设备」。
3. 填写网关名称，例如 `gateway-01`。
4. 产品配置选择默认配置。
5. 打开 **是否网关** 开关。
6. 点击保存。
7. 回到「网关」页面，确认网关已经出现。

> 截图占位：`images/gateway/03-create-gateway.png`
>
> 截图占位：`images/gateway/04-is-gateway.png`
>
> 截图占位：`images/gateway/05-gateway-list.png`

### 3.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/device` | 创建网关设备 |
| GET | `/api/tenant/devices?deviceName=gateway-01` | 按名称查询设备 |
| GET | `/api/device/{gatewayId}` | 查询网关详情 |

创建网关时，`additionalInfo` 必须包含：

```json
{
  "gateway": true
}
```

## 7. 建立网关-子设备关系

### 7.1 关系类型

网关和子设备通过关系关联，统一使用标准关系类型：

```text
Contains
```

方向：

```text
网关设备 --Contains--> 子设备
```

### 7.2 页面操作

1. 打开网关设备详情。
2. 进入「关系 / 关系」页面。
3. 点击「添加」。
4. 关系 type 填写 `Contains`。
5. 方向选择从当前网关指向子设备。
6. 选择目标子设备。
7. 保存。
8. 对每个子设备重复操作。

> 截图占位：`images/gateway/09-relations-tab.png`
>
> 截图占位：`images/gateway/10-add-relation.png`

### 7.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/relation` | 创建关系 |
| GET | `/api/relations?fromId={gatewayId}&fromType=DEVICE&relationType=Contains` | 查询网关关系 |

### 7.4 验证关系

1. 返回网关详情。
2. 进入「网关设备」页签。
3. 确认子设备已经显示。

> 截图占位：`images/gateway/11-gateway-devices.png`

## 8. 网关连接 MQTT

> 平台开通和查询使用 REST API；子设备数据上报使用 MQTT。

### 8.1 连接参数

| 参数 | 值 |
| --- | --- |
| Host | 平台提供 |
| Port | `1883` 或 `8883` |
| 客户端标识 | 网关名称，例如 `gateway-01` |
| 用户名 | 网关访问令牌 |
| 密码 | 空 |
| 心跳间隔 | 60 秒 |
| 清理会话 | `true` |
| QoS | `1` |

### 8.2 MQTT 主题

| 主题 | 方向 | 用途 |
| --- | --- | --- |
| `v1/gateway/connect` | 上行 | 子设备上线 |
| `v1/gateway/disconnect` | 上行 | 子设备下线 |
| `v1/gateway/telemetry` | 上行 | 子设备遥测和事件 |
| `v1/gateway/attributes` | 上行 | 子设备属性 |
| `v1/gateway/attributes/request` | 上行 | 请求子设备属性 |
| `v1/gateway/rpc` | 上行 | 子设备 RPC 响应 |

### 8.3 子设备上线

```json
{
  "device": "sub-device-01",
  "type": "<DeviceProfileName>"
}
```

### 8.4 子设备遥测

```json
{
  "sub-device-01": [
    {
      "ts": 1790000000000,
      "values": {
        "temperature": 25.6,
        "humidity": 60
      }
    }
  ]
}
```

### 8.5 子设备下线

```json
{
  "device": "sub-device-01"
}
```

### 8.6 子设备属性上报

```json
{
  "sub-device-01": {
    "temperature": 25.6,
    "humidity": 60
  }
}
```

### 8.7 请求子设备属性

```json
{
  "id": 1,
  "device": "sub-device-01",
  "client": false,
  "key": "temperature"
}
```

或一次请求多个键：

```json
{
  "id": 2,
  "device": "sub-device-01",
  "client": false,
  "keys": ["temperature", "humidity"]
}
```

### 8.8 订阅和发布建议

- 网关使用固定客户端标识，避免频繁重连。
- 保持心跳间隔，断线后指数退避重连。
- 子设备上线后先发送一次 `v1/gateway/connect`。
- 子设备长时间离线时发送 `v1/gateway/disconnect`。
- 遥测时间戳使用毫秒。
- 单条报文不宜过大，建议控制在 4KB 以内。

### 8.9 安全建议

- 生产环境优先使用 `8883` TLS 端口。
- 访问令牌等同于设备密码，不要写入公开文档或截图。
- 定期轮换令牌，旧令牌失效后及时更新网关配置。
- 网关设备与子设备不要共用令牌。

## 9. 验证在线状态和遥测

### 9.1 页面验证

1. 进入「网关」页面。
2. 确认网关状态为「在线」。
3. 打开网关详情，确认「网关设备」和统计信息。
4. 打开子设备详情，确认「最新遥测」有数据。

> 截图占位：`images/gateway/13-gateway-online.png`
>
> 截图占位：`images/gateway/14-sub-device-telemetry.png`

### 9.2 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/plugins/telemetry/DEVICE/{gatewayId}/values/attributes?keys=active,lastConnectTime,lastDisconnectTime` | 查询网关在线状态 |
| GET | `/api/plugins/telemetry/DEVICE/{subDeviceId}/values/timeseries?keys=<key1>,<key2>` | 查询子设备遥测 |
| GET | `/api/device/{gatewayId}` | 查询网关详情 |

在线判断：

```text
active = true
lastConnectTime > lastDisconnectTime
```

### 9.3 网关状态字段

| 字段 | 说明 |
| --- | --- |
| `active` | 平台根据 MQTT 连接自动维护的在线状态 |
| `lastConnectTime` | 最近上线时间 |
| `lastDisconnectTime` | 最近离线时间 |
| `Version` | 网关版本，可选 |
| 类型 | 网关类型，可选 |
| `active_connectors` | 已启用连接器，可选 |
| `inactive_connectors` | 已禁用连接器，可选 |
| `ALL_ERRORS_COUNT` | 网关错误数，可选 |

> 平台页面中的状态卡会读取上述字段。`Version`、类型、`active_connectors` 等属性由平台侧或网关侧按需维护。

## 10. 网关配置（可选）

### 10.1 常规配置

1. 在「网关」页面点击「常规配置」。
2. 配置平台地址、端口、远程配置、日志、统计等。
3. 保存。

> 截图占位：`images/gateway/15-gateway-configuration.png`

### 10.2 连接器配置

1. 在「网关」页面点击「连接器」。
2. 添加或启用连接器。
3. 配置连接器参数。
4. 保存。

> 截图占位：`images/gateway/16-connectors.png`

### 10.3 子设备连接器归类

如果希望子设备显示在网关页面的按连接器分类页签中，需要给子设备设置属性：

```text
connectorType = mqtt / modbus / opcua / bacnet / ble / can / ...
```

可通过设备属性页面或 REST API 写入。

### 10.4 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/plugins/telemetry/DEVICE/{gatewayId}/values/attributes?keys=general_configuration,active_connectors,inactive_connectors` | 查询网关配置 |
| POST | `/api/plugins/telemetry/DEVICE/{gatewayId}/attributes/SHARED_SCOPE` | 写入共享配置 |
| POST | `/api/plugins/telemetry/DEVICE/{gatewayId}/attributes/SERVER_SCOPE` | 写入服务端配置 |

## 11. 常见问题

| 问题 | 排查 |
| --- | --- |
| 网关一直离线 | 检查 MQTT 连接、访问令牌、`active`、`lastConnectTime` |
| 发布 `v1/gateway/*` 报 `gatewaySessionHandler is null` | 网关设备未开启网关模式 |
| 子设备不显示在网关页面 | 检查关系类型是否为 `Contains`，方向是否从网关指向子设备 |
| 子设备遥测无数据 | 检查 MQTT 主题、子设备名称、产品配置 |
| 401 Unauthorized | JWT 过期或未带 `X-Authorization` |
| 403 Forbidden | 账号权限不足 |
| 409 Conflict | 设备名称已存在 |
| 网关名称或状态显示异常 | 平台 仪表板 状态卡配置问题，联系平台管理员 |
| 设备创建成功但无产品配置 | 创建时补充 `deviceProfileId` |
| 子设备不在连接器页签中 | 子设备缺少 `connectorType` 属性 |
