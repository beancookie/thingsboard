> 适用对象：系统管理员、平台运维人员、租户开通人员

## 1. 文档说明

### 1.1 适用对象

- 平台系统管理员
- 平台运维和租户开通人员
- 负责租户配置和租户管理员账号维护的人员

### 1.2 权限要求

- 「租户」页面仅系统管理员可见。
- 租户管理员不能进入租户管理页面，只能管理本租户内部资源。
- 客户用户不能进入租户管理页面。
- 租户管理员由系统管理员创建和维护。

### 1.3 前置条件

- 平台已创建至少一个租户配置。
- 如需发送激活邮件，平台邮件服务已配置。
- 如需自动初始化平台服务账号，平台已完成基础配置。
- 已规划租户名称、资源配额和租户管理员邮箱。

## 2. 租户是什么

租户是平台中的独立工作空间，通常对应一个组织、单位或项目。

租户之间的数据相互隔离。一个租户拥有自己的：

- 租户管理员
- 客户和客户用户
- 设备、资产和产品
- 仪表板、规则链和告警
- 资源配额和速率限制

### 2.1 角色关系

```text
系统管理员
└── 租户
    ├── 租户管理员
    ├── 平台服务账号
    ├── 客户
    │   └── 客户用户
    ├── 设备 / 资产 / 产品
    └── 仪表板 / 规则链 / 告警
```

### 2.2 租户配置

租户配置用于定义租户的资源上限和速率限制，例如：

- 设备、资产、用户、仪表板、边缘最大数量
- 资源文件和 OTA 包大小上限
- 传输消息和数据点限制
- 规则引擎和 JS 执行次数限制
- 各类速率限制
- 数据存储 TTL

创建租户时必须选择一个租户配置。未指定时使用默认租户配置。

### 2.3 平台服务账号

平台服务账号由系统自动管理，用于产品资源初始化。

- 创建租户后，平台会尝试自动初始化服务账号。
- 初始化成功后，产品资源可以正常创建和更新。
- 初始化失败时，可以在租户详情页手动重试。

## 4. 创建租户

### 4.1 页面操作

1. 在「租户」页面点击「新增租户」。
2. 填写租户名称，例如 `示例租户`。
3. 选择租户配置。
4. 可选选择租户主页仪表板。
5. 填写联系人、国家、城市、州/省、邮编、地址、电话和邮箱。
6. 可选填写描述。
7. 点击保存。
8. 等待平台服务账号自动初始化。
9. 初始化成功后关闭弹窗。

> 截图占位：`images/tenants/03-create-tenant.png`

### 4.2 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 租户名称，建议在平台内唯一 |
| 租户配置 | 是 | 决定资源配额和速率限制 |
| 主页仪表板 | 否 | 租户用户登录后的默认主页 |
| 隐藏主页仪表板工具栏 | 否 | 是否隐藏工具栏 |
| 国家 | 否 | 联系人国家 |
| 城市 | 否 | 联系人城市 |
| 州/省 | 否 | 联系人州或省 |
| 邮编 | 否 | 联系人邮编 |
| 地址 | 否 | 联系地址 |
| 地址 2 | 否 | 补充地址 |
| 电话 | 否 | 联系电话 |
| 邮箱 | 否 | 联系邮箱 |
| 描述 | 否 | 租户备注 |

> 截图占位：`images/tenants/05-tenant-contact.png`
>
> 截图占位：`images/tenants/06-tenant-home-dashboard.png`

### 4.3 创建后初始化平台服务账号

保存租户后，平台会自动弹出「初始化平台服务账号」对话框。

成功时：

- 显示初始化成功。
- 显示平台服务账号用户名。
- 点击关闭即可。

失败时：

- 页面显示失败原因。
- 点击「重试」重新初始化。
- 也可以稍后在租户详情页点击「初始化平台服务账号」。

> 截图占位：`images/tenants/07-vendor-account.png`
>
> 截图占位：`images/tenants/08-vendor-account-success.png`

### 4.4 创建租户 API

```text

GET  /api/tenant/info/{tenantId}
```

平台服务账号 API：


## 6. 租户管理员

### 6.1 页面入口

方式一：

1. 进入「租户」页面。
2. 在租户行点击「管理租户管理员」。

方式二：

1. 打开租户详情。
2. 点击「管理租户管理员」。

页面路径：

```text

```

### 6.2 租户管理员列表

列表字段：

| 字段 | 说明 |
| --- | --- |
| 创建时间 | 用户创建时间 |
| 名 | 名字 |
| 姓 | 姓氏 |
| 邮箱 | 登录邮箱 |

操作：

- 查看详情

- 删除用户

### 6.3 新增租户管理员

1. 在租户管理员列表点击「新增用户」。
2. 填写邮箱，邮箱是登录账号，必须唯一。
3. 填写名、姓和电话。
4. 选择语言和单位制。
5. 配置默认仪表板和主页仪表板。
6. 选择激活方式。
7. 点击添加。

| 方式 | 说明 |
| --- | --- |
| 显示激活链接 | 创建完成后直接显示链接 |
| 发送激活邮件 | 平台向邮箱发送激活链接 |

如果邮件服务未配置，请使用「显示激活链接」。

> 截图占位：`images/tenants/11-activation-link.png`

## 7. 平台服务账号

### 7.1 用途

平台服务账号用于：

- 产品创建和资源初始化
- 平台内部资源初始化
- 产品配置、资产和规则链初始化

不要把它和普通租户管理员账号混用。

### 7.2 初始化方式

**自动初始化**

创建租户后自动执行。

**手动初始化**

1. 打开租户详情。
2. 点击「初始化平台服务账号」。
3. 等待初始化结果。
4. 失败时点击「重试」。

### 7.3 初始化失败排查

| 问题 | 排查 |
| --- | --- |
| 平台未完成基础配置 | 检查平台配置和服务状态 |
| 租户已存在服务账号 | 可查询现有账号，避免重复创建 |
| 网络或认证失败 | 检查服务间网络、认证配置和日志 |
| 初始化一直失败 | 查看平台后端日志 |

### 7.4 平台服务账号 API

```text
GET  /api/thing-model/admin/tenants/{tenantId}/account
POST /api/thing-model/admin/tenants/{tenantId}/provision
POST /api/thing-model/admin/tenants/{tenantId}/provision-auto?force=false
```

## 9. 资源与权限边界

### 9.1 系统管理员

- 创建和维护租户。
- 选择和维护租户配置。
- 创建租户管理员。
- 初始化平台服务账号。
- 删除租户。

### 9.2 租户管理员

- 管理本租户的客户和客户用户。
- 管理本租户的设备、资产、产品、仪表板和规则链。
- 不能访问其他租户的数据。
- 不能进入租户管理页面。

### 9.3 客户用户

- 只能看到分配给本客户或公开的资源。
- 不能管理租户和客户。

### 9.4 数据隔离

- 租户之间数据隔离。
- 跨租户访问会被拒绝。
- 导入导出资源时注意租户 ID和实体 ID 是否属于当前环境。

## 10. 常见问题

| 问题 | 排查 |
| --- | --- |
| 看不到「租户」菜单 | 只有系统管理员可见，检查当前账号权限 |
| 创建租户时没有租户配置 | 先创建租户配置，或设置为默认租户配置 |
| 租户管理员无法登录 | 检查是否已激活、账号是否被禁用、邮箱是否正确 |
| 激活邮件发送失败 | 检查邮件服务，或改用「显示激活链接」 |
| 平台服务账号初始化失败 | 检查平台配置和日志，然后点击重试 |
| 产品创建提示服务账号缺失 | 检查该租户的平台服务账号是否初始化成功 |
| 租户资源达到上限 | 调整租户配置中的数量或速率限制 |
| 删除租户失败 | 检查是否有未处理资源或平台限制 |
| 租户名称冲突 | 换一个名称重试 |
| 删除租户后数据无法恢复 | 删除前必须备份并确认，生产环境需审批 |
| 租户管理员看不到客户菜单 | 确认账号权限是租户管理员且已激活 |
| 租户之间数据串扰 | 检查导入资源和 API 调用是否使用了错误租户 ID |
