- 每个功能一个手册文件，使用 `功能名称使用手册.md` 命名。
- 每个功能的截图放在 `images/<功能>/` 下。
- 新增手册时，请同时更新本索引。
- 截图命名建议：`NN-简短说明.png`，例如 `03-create-gateway.png`。
- 截图清单放在各功能的 `images/<功能>/README.md` 中。

## 新增手册流程

1. 复制 `_template.md`。
2. 重命名为 `功能名称使用手册.md`。
3. 按模板填写内容，保留章节编号。
4. 在「手册列表」中增加一行。
5. 在 `images/<功能>/` 下创建截图清单 `README.md`。
6. 补充截图后，检查正文中的截图占位路径是否存在。

## 截图规范

各手册中的截图占位使用如下格式：

```text
> 截图占位：`images/gateway/03-create-gateway.png`
```

截图补充后，保留图片文件即可，无需修改正文结构。

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏访问令牌、密码、真实客户数据。
- 图片宽度建议 1200px 以上，保持清晰。
