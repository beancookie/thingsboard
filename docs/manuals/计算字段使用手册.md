## 2. 计算字段是什么

计算字段用于基于实体已有的属性、遥测或关联实体数据，计算出新的属性或遥测值。

常见用途：

- 单位换算
- 阈值判断
- 设备健康分
- 多设备数据聚合
- 父子实体数据传播
- 地理围栏判断
- 按时间窗口统计平均值、最大值、总和等

### 2.1 基本流程

```text
实体数据
  -> 计算字段读取参数
  -> 执行表达式或脚本
  -> 生成结果
  -> 输出为属性或时间序列
  -> 保存、推送 WebSocket 或交给规则链
```

### 2.2 计算字段和告警规则的区别

| 功能 | 用途 |
| --- | --- |
| 计算字段 | 生成新的属性或遥测值 |
| 告警规则 | 根据条件创建和清除告警 |

告警规则请见 [告警与通知使用手册](告警与通知使用手册.md)。

## 4. 创建计算字段

### 4.1 页面操作

1. 在「计算字段」页面点击「创建计算字段」。
2. 填写名称。
3. 选择作用实体。
4. 选择计算字段类型。
5. 配置参数和表达式或脚本。
6. 配置输出。
7. 可选配置调试设置。
8. 点击保存。

> 截图占位：`images/calculated-fields/04-create-cf.png`

### 4.2 基本字段

| 字段 | 说明 |
| --- | --- |
| 名称 | 计算字段名称 |
| 实体 | 计算字段作用的设备、资产或其他实体 |
| 类型 | 计算字段计算方式 |
| 调试设置 | 记录调试事件 |
| 参数 | 计算所需的输入 |
| 输出 | 计算结果的保存方式 |

### 4.3 在实体详情页创建

也可以在设备配置、资产配置等实体的「计算字段」页签中创建。

区别：

- 从计算字段页面创建时，需要手动选择实体。
- 从实体详情页创建时，实体会自动带入。

## 5. 计算字段类型

### 5.1 简单

基于参数做简单算术计算。

示例：

```text
(temperature - 32) * 5 / 9
```

适合：

- 单位换算
- 简单加减乘除
- 简单阈值计算

> 截图占位：`images/calculated-fields/05-simple-config.png`

### 5.2 脚本

使用 TBEL 脚本对参数进行计算。

示例：

```text
return Math.max(0, 100 - errorCount * 10);
```

适合：

- 复杂条件
- 字符串处理
- 多参数组合
- 需要函数和逻辑判断的计算

> 截图占位：`images/calculated-fields/06-script-config.png`

### 5.3 地理围栏

根据实体 GPS 坐标判断实体是否进入或离开地理围栏区域组。

主要配置：

- 纬度时间序列键
- 经度时间序列键
- 地理围栏区域组
- 报告策略
- 关联方向
- 区域组刷新间隔

适合：

- 车辆进出区域
- 设备进入工地
- 资产离开指定范围

> 截图占位：`images/calculated-fields/09-geofencing.png`

### 5.4 传播

把数据传播到关联的父级或子级实体。

主要配置：

- 传播路径
- 关联方向和层级
- 参数
- 要传播的数据
- 输出键

适合：

- 子设备数据汇总到父设备
- 区域数据传播到上级资产

> 截图占位：`images/calculated-fields/10-propagation.png`

### 5.5 关联实体聚合

聚合来自关联实体的最新数据。

主要配置：

- 关联路径
- 参数
- 指标
- 聚合方式
- 去重间隔
- 定时更新

适合：

- 多个传感器取平均值
- 多个子设备求和
- 关联设备最大值

> 截图占位：`images/calculated-fields/11-related-aggregation.png`

### 5.6 时间序列数据聚合

聚合当前实体的历史时间序列数据。

主要配置：

- 参数
- 指标
- 聚合间隔
- 聚合周期
- 输出

适合：

- 每小时平均值
- 每天最大值
- 每周总和
- 月度统计

> 截图占位：`images/calculated-fields/12-entity-aggregation.png`

## 6. 参数配置

### 6.1 参数类型

| 类型 | 说明 |
| --- | --- |
| 属性 | 读取实体属性 |
| 最新遥测 | 读取实体最新遥测值 |
| 时间序列滚动 | 读取时间窗口内的遥测数据 |

### 6.2 参数实体

| 实体 | 说明 |
| --- | --- |
| 当前实体 | 计算字段所属实体 |
| 设备 | 指定设备 |
| 资产 | 指定资产 |
| 客户 | 指定客户 |
| 当前租户 | 当前租户 |
| 当前所有者 | 实体所有者 |
| 关联实体 | 按关系路径查找 |

### 6.3 属性范围

| 范围 | 说明 |
| --- | --- |
| 服务端属性 | 服务端维护的属性 |
| 客户端属性 | 设备上报的属性 |
| 共享属性 | 服务端和设备共享的属性 |

### 6.4 参数建议

- 参数名称要能表达业务含义。
- 为参数设置默认值，避免数据缺失时计算失败。
- 时间窗口不要过大，避免影响性能。
- 关联路径要明确方向和层级。

> 截图占位：`images/calculated-fields/07-arguments.png`

## 7. 输出配置

### 7.1 输出类型

| 输出类型 | 说明 |
| --- | --- |
| 属性 | 保存为属性 |
| 时间序列 | 保存为遥测时间序列 |

属性输出需要配置：

- 属性范围
- 输出策略
- 默认小数位数
- 是否仅在值变化时更新
- 是否发送属性更新通知
- 是否保存到数据库
- 是否发送 WebSocket
- 是否发送到计算字段

时间序列输出需要配置：

- 输出策略
- 保存到时间序列
- 保存到最新值
- 发送 WebSocket
- 发送到计算字段
- 自定义 TTL
- 默认小数位数

### 7.2 输出策略

| 策略 | 说明 |
| --- | --- |
| 立即处理 | 计算结果直接保存或推送 |
| 通过规则链处理 | 把结果交给规则链继续处理 |

### 7.3 输出键

输出键是最终保存的属性名或遥测键名。

建议：

- 使用英文、数字和下划线。
- 不要和已有键冲突。
- 单位换算后的键名带上单位，例如 `temperature_c`。

> 截图占位：`images/calculated-fields/08-output.png`

## 8. 典型示例

### 8.1 华氏温度转摄氏温度

类型：简单

参数：

```text
temperature：当前实体最新遥测
```

表达式：

```text
(temperature - 32) * 5 / 9
```

输出：

```text
类型：时间序列
输出键：temperature_c
```

### 8.2 设备健康分

类型：脚本

参数：

```text
errorCount：当前实体最新遥测
```

脚本：

```text
return Math.max(0, 100 - errorCount * 10);
```

输出：

```text
类型：属性
属性范围：服务端属性
输出键：health_score
```

### 8.3 关联设备平均湿度

类型：关联实体聚合

配置：

- 关联路径：当前实体到关联设备
- 参数：`humidity`
- 指标：平均值
- 去重间隔：60 秒
- 输出键：`avg_humidity`

### 8.4 每小时平均温度

类型：时间序列数据聚合

配置：

- 参数：`temperature`
- 指标：平均值
- 聚合间隔：1 小时
- 输出键：`temperature_hourly_avg`

### 8.5 车辆进出工地

类型：地理围栏

配置：

- 纬度时间序列键：`latitude`
- 经度时间序列键：`longitude`
- 区域组：工地围栏
- 报告策略：存在状态和转换事件
- 输出键：`site_presence`

## 9. 调试与验证

### 9.1 开启调试

1. 打开计算字段。
2. 开启调试设置。
3. 保存。
4. 在「事件」页签查看调试事件。
5. 调试完成后关闭调试。

> 截图占位：`images/calculated-fields/14-debug.png`

### 9.2 测试脚本

1. 打开计算字段。
2. 点击测试脚本。
3. 输入参数测试值。
4. 查看表达式或脚本返回结果。
5. 调整后重新测试。

> 截图占位：`images/calculated-fields/13-test-script.png`

### 9.3 验证输出

1. 让实体上报一条遥测。
2. 查看计算字段是否执行。
3. 在实体「属性」或「最新遥测」中查看输出键。
4. 检查输出值、时间戳和小数位数。
5. 如果使用了规则链输出，检查规则链是否收到消息。

### 9.4 事件页签

计算字段详情中的「事件」页签会显示：

- 调试事件
- 计算字段执行事件

> 截图占位：`images/calculated-fields/15-events.png`

## 10. 在设备配置和资产配置中使用

计算字段也可以从实体详情页维护。

### 10.1 设备配置

1. 打开设备配置详情。
2. 进入「计算字段」页签。
3. 创建或查看该设备配置的计算字段。
4. 该配置下的设备会使用这些计算字段。

### 10.2 资产配置

1. 打开资产配置详情。
2. 进入「计算字段」页签。
3. 创建或查看该资产配置的计算字段。

### 10.3 注意

- 从实体详情页创建时，实体会自动带入。
- 从计算字段页面创建时，需要选择实体。
- 同一实体上的计算字段名称建议保持唯一。

## 11. 权限与最佳实践

- 计算字段只由租户管理员维护。
- 不要在高频数据上配置过多复杂脚本。
- 为参数设置默认值。
- 时间窗口和聚合间隔要结合实际业务。
- 输出键命名要稳定，避免影响仪表板和规则链。
- 生产环境不要长期开启调试。
- 修改计算字段前先导出备份。
- 计算字段和告警规则分开管理。
- 关联聚合要注意关系方向和层级。
- 地理围栏要确认经纬度键和区域组配置正确。

## 12. 常见问题

| 问题 | 排查 |
| --- | --- |
| 计算字段没有执行 | 检查实体是否上报数据、计算字段是否保存、参数是否配置正确 |
| 表达式报错 | 检查参数名称、括号、运算符和默认值 |
| 脚本报错 | 检查 TBEL 语法、返回值和参数类型 |
| 参数取不到值 | 检查参数类型、属性范围、时间序列键和默认值 |
| 输出没有保存 | 检查输出类型、输出策略、保存选项和输出键 |
| 输出值为空 | 检查参数是否有数据、表达式是否返回空值 |
| 关联实体聚合为空 | 检查关系方向、层级和关联实体数据 |
| 时间序列聚合不更新 | 检查聚合间隔、水位线和数据时间戳 |
| 地理围栏不触发 | 检查经纬度键、区域组和报告策略 |
| 调试没有事件 | 检查调试设置、调试有效期和实体是否有数据 |
| 客户用户看不到计算字段 | 计算字段仅租户管理员可管理 |
| 计算字段和告警规则混淆 | 计算字段生成值，告警规则负责创建和清除告警 |
| 修改后结果不对 | 检查是否命中缓存或旧时间戳，重新上报验证 |
| 性能变慢 | 减少参数数量、缩小时间窗口、降低脚本复杂度 |

## 13. API 地址

### 13.1 计算字段 API

```text
GET    /api/calculatedFields?pageSize=100&page=0
GET    /api/calculatedField/{calculatedFieldId}
POST   /api/calculatedField
DELETE /api/calculatedField/{calculatedFieldId}
GET    /api/{entityType}/{entityId}/calculatedFields?pageSize=100&page=0
POST   /api/calculatedField/testScript
GET    /api/calculatedField/{calculatedFieldId}/debug
GET    /api/calculatedFields/names?pageSize=100&page=0
```

### 13.2 实体数据 API

```text
GET  /api/plugins/telemetry/DEVICE/{deviceId}/values/attributes
GET  /api/plugins/telemetry/DEVICE/{deviceId}/values/timeseries
GET  /api/plugins/telemetry/ASSET/{assetId}/values/attributes
GET  /api/plugins/telemetry/ASSET/{assetId}/values/timeseries
```

### 13.3 错误码

| HTTP 状态 | 含义 |
| --- | --- |
| 400 | 请求参数或表达式错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 计算字段或实体不存在 |
| 409 | 名称冲突或资源冲突 |
| 500 | 平台内部错误 |
