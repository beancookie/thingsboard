## 2. 设备是什么

设备是平台中真实接入的对象，可以通过 MQTT、HTTP、CoAP、LwM2M 等协议连接平台并上报数据。

设备主要包含：

- 设备名称和设备 ID
- 产品配置
- 设备凭证
- 客户端属性、共享属性、服务端属性
- 遥测、事件、告警
- 关系
- 在线状态

设备与资产、网关的区别：

| 对象 | 是否真实连接 | 说明 |
| --- | --- | --- |
| 设备 | 是 | 真实设备或网关 |
| 资产 | 否 | 业务对象、分组、产品元数据 |
| 网关 | 是 | 特殊设备，代子设备接入 |

## 4. 新增设备

### 4.1 页面操作

1. 在「设备」页面点击「新增设备」。
2. 填写设备名称，例如 `device-01`。
3. 选择正确的产品配置。该字段必填，且必须与设备所属产品一致。
4. 可选填写标签、固件、软件和描述。
5. 如需作为网关使用，打开 **是否网关** 开关。
6. 点击保存。
7. 保存后配置设备凭证。

> 重要：新增设备时必须选择正确的产品配置。产品配置决定设备的传输方式、绑定规则链和默认行为；选择错误会导致设备无法接入，或遥测无法按产品规则链正确校验。

> 截图占位：`images/devices/03-create-device.png`
>
> 截图占位：`images/devices/04-is-gateway.png`

### 4.2 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 租户内唯一 |
| 产品配置 | 是 | 必须与设备所属产品一致，决定传输方式、规则链和默认行为 |
| 标签 | 否 | 可读标签 |
| 固件 | 否 | 绑定固件 OTA 包 |
| 软件 | 否 | 绑定软件 OTA 包 |
| 设备数据 | 是 | 设备侧配置数据 |
| 是否网关 | 否 | 是否网关设备 |
| 覆盖活动时间 | 否 | 网关设备可用 |
| 描述 | 否 | 保存在 `additionalInfo.description` |

### 4.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/device` | 创建设备 |
| POST | `/api/device-with-credentials` | 创建带凭证的设备 |
| GET | `/api/tenant/deviceInfos?pageSize=100&page=0` | 查询设备信息 |

### 5.3 属性

1. 打开设备详情。
2. 进入「属性」页签。
3. 选择 `CLIENT_SCOPE`、`SHARED_SCOPE` 或 `SERVER_SCOPE`。
4. 查看或新增属性。

默认属性范围是 `CLIENT_SCOPE`。

> 截图占位：`images/devices/07-device-attributes.png`

API 地址：

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/plugins/telemetry/DEVICE/{deviceId}/values/attributes` | 查询设备属性 |
| POST | `/api/plugins/telemetry/DEVICE/{deviceId}/attributes/SERVER_SCOPE` | 写入服务端属性 |
| POST | `/api/plugins/telemetry/DEVICE/{deviceId}/attributes/SHARED_SCOPE` | 写入共享属性 |

### 5.4 遥测

1. 打开设备详情。
2. 进入「最新遥测」页签。
3. 查看设备最新遥测数据。

> 截图占位：`images/devices/08-device-telemetry.png`

API 地址：

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/plugins/telemetry/DEVICE/{deviceId}/values/timeseries` | 查询最新遥测 |
| GET | `/api/plugins/telemetry/DEVICE/{deviceId}/keys/timeseries` | 查询遥测键 |

### 5.5 事件和告警

- 「事件」页签查看设备错误、生命周期等事件。
- 「告警」页签查看设备告警。
- 「告警规则」页签仅租户管理员可见。
- 告警查看、确认、清除和通知配置见 [告警与通知使用手册](告警与通知使用手册.md)。

API 地址：

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/alarm/DEVICE/{deviceId}?pageSize=10&page=0` | 查询设备告警 |
| GET | `/api/events?entityId={deviceId}&entityType=DEVICE` | 查询设备事件 |

## 6. 设备凭证

### 6.1 页面操作

1. 在设备列表或详情页点击「管理凭证」。
2. 查看当前凭证类型和值。
3. 复制访问令牌或更新凭证。
4. 保存。

> 截图占位：`images/devices/09-device-credentials.png`

### 6.2 凭证类型

| 类型 | 说明 |
| --- | --- |
| 访问令牌 | 最常用，作为 MQTT 用户名 |
| MQTT 基础认证 | 用户名、密码、客户端标识 |
| X.509 证书 | 双向 TLS 证书 |
| LwM2M | LwM2M 安全配置 |

凭证类型由产品配置的传输配置决定。

### 6.3 检查连接性

1. 点击「检查连接性」。
2. 页面显示 MQTT、HTTP、CoAP 等连接参数。
3. 按页面提示复制命令或下载证书。

> 截图占位：`images/devices/10-check-connectivity.png`

API 地址：

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/device/{deviceId}/credentials` | 查询设备凭证 |
| POST | `/api/device/credentials` | 更新设备凭证 |
| GET | `/api/device-connectivity/device-connectivity-info` | 查询连接性信息 |

## 7. 设备关系

### 7.1 关系说明

设备可以和其他设备、资产、网关建立关系，例如：

```text
网关设备 --Contains--> 子设备
站点资产 --Contains--> 设备
产品资产 --Manages--> 设备
```

### 7.2 页面操作

1. 打开设备详情。
2. 进入「关系 / 关系」页签。
3. 点击「添加」。
4. 填写关系类型。
5. 选择方向和目标实体。
6. 保存。

> 截图占位：`images/devices/11-device-relations.png`

### 7.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/relation` | 创建关系 |
| GET | `/api/relations?fromId={deviceId}&fromType=DEVICE` | 查询设备关系 |
| DELETE | `/api/relation?fromId={deviceId}&fromType=DEVICE&relationType={type}&toId={targetId}&toType={targetType}` | 删除关系 |

## 8. 客户分配与公开

### 8.1 页面操作

**分配给客户**

1. 在设备列表选择设备。
2. 点击「分配给客户」。

## 9. 设备接入 MQTT（可选）

设备接入参数以「检查连接性」页面为准。常见配置：

| 参数 | 值 |
| --- | --- |
| Host | 平台提供 |
| Port | `1883` 或 `8883` |
| 客户端标识 | 设备名称 |
| 用户名 | 访问令牌 |
| 密码 | 空 |
| 心跳间隔 | 60 秒 |
| 清理会话 | `true` |
| QoS | `1` |

常用主题：

| 主题 | 方向 | 用途 |
| --- | --- | --- |
| `v1/devices/me/telemetry` | 上行 | 遥测和事件 |
| `v1/devices/me/attributes` | 上行/下行 | 客户端属性和共享属性 |
| `v1/devices/me/attributes/request/{id}` | 上行 | 请求服务端属性 |
| `v1/devices/me/attributes/response/{id}` | 下行 | 服务端属性响应 |
| `v1/devices/me/rpc/request/{id}` | 下行 | 平台下发 RPC |
| `v1/devices/me/rpc/response/{id}` | 上行 | 设备返回 RPC 结果 |

> 共享属性推送和 RPC 下行的完整操作、示例代码与排障见 [MQTT推送数据到设备使用手册](MQTT推送数据到设备使用手册.md)。

> 截图占位：`images/devices/13-device-connectivity-info.png`

## 11. 常见问题

| 问题 | 排查 |
| --- | --- |
| 设备无法连接 | 检查产品配置传输配置、凭证、MQTT 地址和端口 |
| 401 Unauthorized | 访问令牌错误或已失效 |
| 设备一直离线 | 检查 MQTT 连接、心跳间隔、网络 |
| 设备没有遥测 | 检查主题、数据格式、产品配置规则链 |
| 没有可用产品配置 | 先创建产品配置 |
| 设备名称冲突 | 设备名称在租户内唯一 |
| 网关主题报 `gatewaySessionHandler is null` | 设备未开启网关模式 |
| 客户看不到设备 | 检查设备是否分配给客户或设为公开 |
| 删除设备失败 | 检查设备是否被关系、规则链或仪表板引用 |
