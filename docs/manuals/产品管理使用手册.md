- 平台租户管理员
- 产品经理、物模型维护人员

- 平台账号需要租户管理员权限。

- 当前租户已初始化厂商服务账号。
- 中国中铁物联网平台已配置默认资产配置。
- 已准备好 TSL 文件，支持腾讯原始物模型或规范 TSL。

## 2. 产品是什么

产品是平台对一类设备的业务抽象，包含：

- 产品标识 产品 ID
- 产品名称、型号、分类
- TSL 物模型
- TSL 版本
- 产品状态

产品发布或同步后，平台会自动创建或更新：

```text
设备配置：产品名称 + 型号
资产：产品 <产品 ID>
规则链：名称等于产品 ID
```

这些资源用于：

- 设备绑定对应的设备配置
- 设备规则链校验遥测和事件
- 保存 TSL 元数据和压缩 schema

产品本身不是设备，不会联网，也不产生遥测。

## 3. 页面入口与列表

### 3.1 页面入口

1. 使用租户管理员账号登录平台。
2. 左侧菜单选择「产品」。
3. 或直接访问：

```text
/entities/products
```

列表字段：

| 字段 | 说明 |

| 名称 | 产品名称 |

| 分类 | 产品分类 |
| TSL 版本 | 物模型版本 |

- 查看详情

## 4. 新建产品

### 4.1 打开新建窗口

1. 在「产品」页面点击「新建产品」。
2. 填写产品信息和 TSL。

> 截图占位：`images/products/03-create-product.png`

### 4.2 填写字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 产品 ID | 是 | 全系统唯一，最长 64 字符 |
| 名称 | 是 | 产品名称，最长 128 字符 |
| 型号 | 否 | 产品型号，最长 64 字符 |
| 分类 | 否 | 产品分类 |
| TSL 版本 | 是 | 默认 `1.0` |
| 严格未知字段 | 否 | 开启后未知字段会校验失败 |
| 物模型 | 是 | TSL JSON |

### 4.3 导入物模型

1. 点击「导入 JSON」。
2. 选择本地物模型文件。
3. 支持腾讯原始物模型和规范 TSL。
4. 平台会自动转换腾讯格式的 `stringenum`、`dataType` 和 结构 `specs`。

> 截图占位：`images/products/04-import-json.png`

### 4.4 校验物模型

1. 点击「校验」。
2. 校验通过后提示成功。
3. 校验失败时，页面列出具体错误和警告。
4. 根据提示修改 TSL 后再次校验。

> 截图占位：`images/products/05-validate.png`

### 4.5 保存并发布

1. 校验通过后点击「保存」。
2. 平台会校验并保存产品。
3. 保存成功后自动同步中国中铁物联网平台。
4. 状态变为「已发布」。
5. 页面跳转到产品详情。

> 截图占位：`images/products/06-product-created.png`

### 4.6 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/thing-model/products` | 创建产品并同步 |
| POST | `/api/thing-model/products/{productId}/thing-model/validate` | 只校验 TSL，不落库 |
| GET | `/api/thing-model/products/{productId}` | 查询产品详情 |

## 6. 编辑物模型

### 6.1 页面操作

1. 在产品详情页点击「编辑物模型」。
2. 修改 TSL 版本、严格未知字段或 TSL 内容。
3. 点击「校验」确认无误。
4. 点击「保存」提交新版本。
5. 保存后自动同步中国中铁物联网平台。

> 截图占位：`images/products/09-edit-thing-model.png`

### 6.2 版本说明

- 同一产品下按 `tslVersion` 管理版本。
- 同一版本内容不同会返回 `409 TSL_VERSION_EXISTS`。
- 提交新版本请递增版本号，例如 `1.0` → `1.1`。
- 产品详情「版本」页签可以查看历史版本和校验和。

> 截图占位：`images/products/10-product-versions.png`

### 6.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| PUT | `/api/thing-model/products/{productId}/thing-model` | 提交新 TSL 版本并同步 |
| GET | `/api/thing-model/products/{productId}/thing-model` | 查询最新 TSL |
| GET | `/api/thing-model/products/{productId}/catalog` | 查询属性、事件、行为目录 |

## 7. 产品同步与状态

### 7.1 状态说明

| 状态 | 含义 |
| --- | --- |
| DRAFT | 草稿，未发布或同步失败 |
| PUBLISHED | 已发布，已同步中国中铁物联网平台 |
| DEPRECATED | 已废弃 |

### 7.2 同步失败

如果产品同步失败：

1. 产品状态保持草稿。
2. 接口返回错误信息。
3. 检查默认资产配置、服务账号、中国中铁物联网平台连通性。
4. 修复后重新同步。

> 截图占位：`images/products/11-product-status.png`

### 7.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/thing-model/products/{productId}/sync` | 对最新版本重新同步中国中铁物联网平台 |

## 8. 删除产品

### 8.1 页面操作

1. 在产品列表或详情页点击「删除产品」。
2. 确认删除。
3. 删除成功后返回产品列表。

> 截图占位：`images/products/12-delete-product.png`

### 8.2 删除限制

删除产品前平台会检查产品下是否存在设备：

- 有设备：返回 `409 PRODUCT_HAS_DEVICES`，不删除任何数据。
- 无设备：删除产品、TSL、独占的设备配置、资产、规则链。

### 8.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| DELETE | `/api/thing-model/products/{productId}` | 删除产品及相关资源 |

## 9. 产品与设备、资产、规则链

### 9.1 产品与设备

- 设备通过设备配置绑定产品。
- 设备上报数据后，由产品规则链校验遥测和事件。
- 注册设备前，产品必须已同步。

### 9.2 产品与资产

- 产品资产保存 TSL、版本、属性/事件/行为数量和压缩 schema。
- 查看方式见 [资产管理使用手册](资产管理使用手册.md)。
- 不建议手工修改产品资产。

### 9.3 产品与规则链

- 规则链名称等于 产品 ID。
- 规则链绑定到产品设备配置的默认规则链。
- 规则链负责 TSL 校验、遥测保存和 Kafka 输出。

## 10. 常见问题

| 问题 | 排查 |
| --- | --- |
| 没有「产品」菜单 | 确认当前账号是租户管理员 |
| 保存失败，提示缺少服务账号 | 检查租户服务账号是否已初始化 |
| 保存失败，提示未配置默认资产模板 | 在 `/profiles/assetProfiles` 设置默认资产配置 |
| TSL 校验失败 | 根据页面错误列表修正属性、事件或行为 |
| 产品 ID 已存在 | 产品 ID 全系统唯一，不同租户也不能重复 |
| 同一版本内容不同 | 递增 TSL 版本号 |
| 产品状态一直是草稿 | 检查同步失败原因，调用 `/sync` 重试 |
| 删除产品返回 409 | 产品下存在设备，先处理设备 |
| 设备无法接入 | 确认产品设备配置和规则链已生成 |

### 11.2 错误码

| HTTP 状态 | 含义 |
| --- | --- |
| 400 | 请求参数或 TSL 校验错误 |
| 401 | 未认证 |
| 403 | 无权限，或不是当前租户 |
| 404 | 产品不存在 |
| 409 | 产品 ID 冲突、版本冲突或产品下存在设备 |
| 502 | 中国中铁物联网平台同步失败 |
