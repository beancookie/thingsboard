## 1. 文档说明

### 1.1 适用对象

- 第三方硬件厂商
- 第三方设备接入集成商
- 平台侧开通和联调人员

### 1.2 权限要求

- 平台账号需要租户管理员权限。
- 平台侧操作可以通过平台页面完成，也可以通过 REST API 完成。
- 设备数据上报使用 MQTT。

### 1.3 操作流程总览
