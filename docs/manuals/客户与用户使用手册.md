## 1. 文档说明

### 1.1 适用对象

- 平台租户管理员
- 客户管理员
- 负责客户交付和账号运维的人员

### 1.2 权限要求

- 「客户」页面仅租户管理员可见。
- 客户用户看不到客户管理菜单，只能使用分配给本客户或公开的资源。
- 租户管理员由系统管理员在「租户」页面维护。
- 客户用户由租户管理员在客户页面创建和维护。

### 1.3 前置条件

- 当前租户已创建。
- 已创建至少一个客户。
- 需要分配的设备、资产、仪表板或边缘已存在。
- 如使用「发送激活邮件」，平台邮件服务需已配置。

## 2. 客户与用户是什么

### 2.1 客户

客户是平台中的业务组织或归属边界，不是登录账号。

客户用于把以下资源归到一个组织下：

- 客户用户
- 设备
- 资产
- 仪表板
- 边缘

客户用户只能看到分配给本客户的资源，以及平台设为公开的资源。

### 2.2 用户

用户是平台登录账号，拥有不同的权限级别：

| 权限 | 说明 |
| --- | --- |
| 系统管理员 | 管理租户、租户管理员和平台级配置 |
| 租户管理员 | 管理本租户的客户、设备、资产、仪表板等 |
| 客户用户 | 客户用户，只能使用本客户或公开的资源 |

客户用户属于某一个客户；租户管理员属于租户，不归属于客户。

### 2.3 关系示意

```text
租户
├── 租户管理员
├── 设备 / 资产 / 仪表板 / 边缘
└── 客户
    ├── 客户用户
    ├── 客户设备
    ├── 客户资产
    ├── 客户仪表板
    └── 客户边缘
```

### 2.4 可见性规则

| 资源状态 | 客户用户是否可见 |
| --- | --- |
| 分配给本客户 | 可见 |
| 设为公开 | 所有客户用户可见 |
| 未分配且未公开 | 不可见 |
| 分配给其他客户 | 不可见 |

## 3. 客户管理

### 3.1 页面入口

1. 使用租户管理员账号登录平台。
2. 左侧菜单选择「客户」。
3. 或直接访问：

```text
/customers
```

### 3.2 客户列表

列表字段：

| 字段 | 说明 |
| --- | --- |
| 创建时间 | 客户创建时间 |
| 名称 | 客户名称 |
| 邮箱 | 联系邮箱 |
| 国家 | 联系人国家 |
| 城市 | 联系人城市 |

列表和行操作：

- 新增客户
- 查看详情
- 管理客户用户
- 管理客户设备
- 管理客户资产
- 管理客户仪表板
- 管理客户边缘
- 删除客户
- 复制客户 ID

> 截图占位：`images/customers/02-customer-list.png`

### 3.3 新增客户

1. 在「客户」页面点击「新增客户」。
2. 填写客户名称，例如 `示例客户`。
3. 填写联系人、国家、城市、州/省、邮编、地址、电话和邮箱。
4. 可选选择客户主页仪表板。
5. 可选填写描述。
6. 点击保存。

> 截图占位：`images/customers/03-create-customer.png`

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 客户名称，建议在租户内保持唯一 |
| 国家 | 否 | 联系人国家 |
| 城市 | 否 | 联系人城市 |
| 州/省 | 否 | 联系人州或省 |
| 邮编 | 否 | 联系人邮编 |
| 地址 | 否 | 联系地址 |
| 地址 2 | 否 | 补充地址 |
| 电话 | 否 | 联系电话 |
| 邮箱 | 否 | 联系邮箱 |
| 主页仪表板 | 否 | 客户用户登录后的默认主页 |
| 隐藏主页仪表板工具栏 | 否 | 是否隐藏工具栏 |
| 描述 | 否 | 客户备注 |

### 3.4 客户详情

客户详情页签：

- 属性
- 最新遥测
- 告警规则
- 告警
- 关系
- 审计日志
- 版本控制

客户详情按钮：

- 打开详情页
- 管理用户
- 管理资产
- 管理设备
- 管理仪表板
- 管理边缘
- 删除客户
- 复制客户 ID

> 截图占位：`images/customers/04-customer-details.png`

### 3.5 公开客户

平台内置一个公开客户，用于承载公开设备、公开资产和公开仪表板。

- 公开客户通常为只读。
- 不要修改或删除公开客户。
- 公开客户下的资源对所有客户用户可见。

### 3.6 删除客户

删除客户前请确认：

- 该客户下的用户和设备是否还需要保留。
- 是否需要先取消设备、资产、仪表板和边缘分配。
- 删除后关联数据可能无法恢复。

### 3.7 客户 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/customers?pageSize=100&page=0` | 查询客户列表 |
| GET | `/api/customers?customerIds={customerIds}` | 按 ID 批量查询客户 |
| GET | `/api/customer/{customerId}` | 查询客户详情 |
| POST | `/api/customer` | 创建或更新客户 |
| DELETE | `/api/customer/{customerId}` | 删除客户 |

## 4. 客户用户管理

### 4.1 页面入口

方式一：

1. 进入「客户」页面。
2. 在客户行点击「管理客户用户」。

方式二：

1. 打开客户详情。
2. 点击「管理用户」。

页面路径：

```text
/customers/{customerId}/users
```

### 4.2 客户用户列表

列表字段：

| 字段 | 说明 |
| --- | --- |
| 创建时间 | 用户创建时间 |
| 名 | 名字 |
| 姓 | 姓氏 |
| 邮箱 | 登录邮箱 |

列表操作：

- 新增用户
- 查看详情
- 以用户身份登录（需开启用户令牌访问）
- 删除用户

> 截图占位：`images/customers/05-customer-users.png`

### 4.3 新增客户用户

1. 在客户用户列表点击「新增用户」。
2. 填写邮箱，邮箱是登录账号，必须唯一。
3. 填写名、姓和电话。
4. 选择语言和单位制。
5. 配置默认仪表板和主页仪表板。
6. 选择激活方式。
7. 点击添加。

> 截图占位：`images/customers/06-add-customer-user.png`

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 邮箱 | 是 | 登录账号，必须唯一 |
| 名 | 否 | 用户名字 |
| 姓 | 否 | 用户姓氏 |
| 电话 | 否 | 联系电话 |
| 语言 | 否 | 界面语言，默认跟随浏览器 |
| 单位制 | 否 | 默认自动 |
| 默认仪表板 | 否 | 用户登录后的默认仪表板 |
| 始终全屏 | 否 | 默认仪表板是否全屏 |
| 主页仪表板 | 否 | 用户主页仪表板 |
| 隐藏主页仪表板工具栏 | 否 | 是否隐藏工具栏 |
| 描述 | 否 | 用户备注 |

### 4.4 激活方式

新增用户时支持两种激活方式：

| 方式 | 说明 |
| --- | --- |
| 显示激活链接 | 创建完成后直接显示链接，适合现场交付 |
| 发送激活邮件 | 平台向用户邮箱发送激活链接 |

如果邮件服务未配置，请使用「显示激活链接」，手动把链接交给用户。

> 截图占位：`images/customers/07-activation-method.png`
>
> 截图占位：`images/customers/08-activation-link.png`

### 4.5 用户详情与操作

用户详情页支持：

- 显示激活链接
- 重新发送激活邮件
- 启用账号
- 禁用账号
- 以用户身份登录
- 删除用户
- 复制用户 ID

> 截图占位：`images/customers/09-user-details.png`

用户详情页签：

- 属性
- 最新遥测
- 关系
- 审计日志
- API 密钥

### 4.6 启用、禁用和删除

- **禁用账号**：用户无法登录，但保留用户数据和审计记录，适合人员离职或暂停使用。
- **启用账号**：恢复用户登录能力。
- **删除用户**：永久删除用户，操作不可恢复。
- 不能删除当前登录的自己。

### 4.7 以用户身份登录

开启用户令牌访问后，租户管理员可以在用户列表或详情页点击「以用户身份登录」，用于排障和验证客户视角。

使用建议：

- 仅在排障时使用。
- 操作会记录到审计日志。
- 使用完成后及时退出。

### 4.8 租户管理员账号

租户管理员由系统管理员维护：

1. 系统管理员进入「租户」页面。
2. 选择租户并点击「管理租户管理员」。
3. 新增或维护租户管理员用户。

页面路径：

```text
/tenants/{tenantId}/users
```

## 5. 资源分配与可见性

### 5.1 分配设备

1. 进入「设备」页面。
2. 选择设备。
3. 点击「分配给客户」。
4. 选择目标客户并保存。

也可以从客户列表进入「管理客户设备」，查看或分配该客户的设备。

> 截图占位：`images/customers/10-assign-resource.png`

### 5.2 分配资产

1. 进入「资产」页面。
2. 选择资产。
3. 点击「分配给客户」。
4. 选择目标客户并保存。

### 5.3 分配仪表板

1. 进入「仪表板」页面。
2. 选择仪表板。
3. 点击「分配给客户」。
4. 选择目标客户并保存。

### 5.4 分配边缘

1. 进入「边缘」页面。
2. 选择边缘实例。
3. 点击「分配给客户」。
4. 选择目标客户并保存。

### 5.5 公开资源

- 设备、资产、仪表板和边缘都可以设为公开。
- 公开资源对所有客户用户可见。
- 公开资源通常挂在公开客户下。
- 公开前请确认数据不包含敏感信息。

> 截图占位：`images/customers/11-public-vs-assigned.png`

### 5.6 取消分配

在对应资源页面选择「取消分配」，或从客户详情中取消资源关联。

取消分配后：

- 该客户用户将不再看到该资源。
- 如果资源同时被设为公开，仍然对所有客户用户可见。

### 5.7 分配 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/customer/{customerId}/device/{deviceId}` | 分配设备给客户 |
| DELETE | `/api/customer/device/{deviceId}` | 取消设备分配 |
| POST | `/api/customer/public/device/{deviceId}` | 设为公开设备 |
| POST | `/api/customer/{customerId}/asset/{assetId}` | 分配资产给客户 |
| DELETE | `/api/customer/asset/{assetId}` | 取消资产分配 |
| POST | `/api/customer/public/asset/{assetId}` | 设为公开资产 |
| POST | `/api/customer/{customerId}/dashboard/{dashboardId}` | 分配仪表板给客户 |
| DELETE | `/api/customer/{customerId}/dashboard/{dashboardId}` | 取消仪表板分配 |
| POST | `/api/customer/public/dashboard/{dashboardId}` | 设为公开仪表板 |
| POST | `/api/customer/{customerId}/edge/{edgeId}` | 分配边缘给客户 |
| DELETE | `/api/customer/edge/{edgeId}` | 取消边缘分配 |
| POST | `/api/customer/public/edge/{edgeId}` | 设为公开边缘 |

## 6. 仪表板配置

### 6.1 客户主页仪表板

客户详情中的「主页仪表板」用于设置该客户用户登录后的默认主页。

- 可选择该客户可用的仪表板。
- 可勾选「隐藏主页仪表板工具栏」。
- 客户用户登录后会优先看到该主页。

### 6.2 用户默认仪表板和主页仪表板

用户详情中可以分别设置：

| 配置 | 说明 |
| --- | --- |
| 默认仪表板 | 用户登录后的默认仪表板 |
| 始终全屏 | 默认仪表板是否全屏显示 |
| 主页仪表板 | 用户点击主页时打开的仪表板 |
| 隐藏主页仪表板工具栏 | 是否隐藏工具栏 |

> 截图占位：`images/customers/12-dashboard-settings.png`

### 6.3 优先级建议

建议按以下顺序配置：

1. 先创建并分配仪表板给客户。
2. 再配置客户主页仪表板。
3. 最后按需为单个用户覆盖默认仪表板。

这样大多数客户用户可以直接使用客户级主页，特殊用户再单独调整。

## 7. 权限与安全建议

- 客户用户只应看到本客户或公开资源，分配前确认数据范围。
- 激活链接相当于初始密码，不要发送到公共群组或无关人员。
- 人员离职优先「禁用账号」，确认无影响后再删除。
- 不要删除公开客户或公开客户下的系统资源。
- 「以用户身份登录」仅用于排障，操作会进入审计日志。
- 删除客户前先备份或导出需要保留的数据。
- 定期检查客户用户列表，清理长期未使用账号。
- 公开资源上线前检查是否包含敏感遥测、告警或属性。

## 8. 常见问题

| 问题 | 排查 |
| --- | --- |
| 客户用户看不到设备 | 检查设备是否分配给该客户或设为公开 |
| 客户用户看不到资产 | 检查资产是否分配给该客户或设为公开 |
| 客户用户看不到仪表板 | 检查仪表板是否分配给该客户或设为公开 |
| 客户用户看不到「客户」菜单 | 客户用户没有客户管理权限，这是正常现象 |
| 用户无法登录 | 检查用户是否已激活、账号是否被禁用、邮箱是否正确 |
| 激活链接失效 | 重新生成或重新发送激活链接 |
| 邮件发送失败 | 检查平台邮件服务配置，或改用「显示激活链接」 |
| 无法删除用户 | 不能删除当前登录的自己，或用户仍被其他数据引用 |
| 客户名称冲突 | 客户名称建议在租户内唯一，换一个名称重试 |
| 删除客户失败 | 检查是否有未处理的资源、用户或关联数据 |
| 分配后仍然看不到 | 让客户用户重新登录，或检查资源是否被取消分配 |
| 公开资源泄露敏感数据 | 立即取消公开，并检查设备、资产和仪表板数据 |
