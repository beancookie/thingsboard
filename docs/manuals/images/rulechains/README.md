# 规则引擎手册截图清单

本目录存放 `规则引擎使用手册.md` 使用的截图。

建议按以下文件名补充：

| 文件名 | 页面/内容 |
| --- | --- |
| `01-rulechain-menu.png` | 规则引擎菜单入口 |
| `02-rulechain-list.png` | 规则链列表 |
| `03-create-rulechain.png` | 创建规则引擎 |
| `04-rulechain-editor.png` | 规则链编辑器整体布局 |
| `05-node-library.png` | 节点库分类和搜索 |
| `06-add-node.png` | 添加规则节点 |
| `07-node-config.png` | 节点配置抽屉 |
| `08-link-label.png` | 节点连接标签 |
| `09-debug-mode.png` | 开启调试模式 |
| `10-debug-events.png` | 规则链/节点调试事件 |
| `11-save-rulechain.png` | 保存规则链 |
| `12-set-root.png` | 设为根规则引擎 |
| `13-import-export.png` | 导入/导出规则链 |
| `14-scene-linkage.png` | 多设备场景联动规则链 |
| `15-rpc-config.png` | RPC 调用请求 节点配置 |
| `16-version-control.png` | 规则链版本控制 |
| `17-rulechain-details.png` | 规则链详情页 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏设备 ID、访问令牌、外部系统地址和真实业务数据。
- 图片宽度建议 1200px 以上，保持清晰。
- 规则链截图尽量保留完整节点和连接关系，便于对照配置。
