# 场景联动截图清单

本目录存放 `多设备场景联动使用手册.md` 使用的截图。

建议按以下文件名补充：

| 文件名 | 页面/内容 |
| --- | --- |
| `01-scene-overview.png` | 场景联动概念和整体流程 |
| `02-device-relations.png` | 设备关系配置 |
| `03-create-scene-rulechain.png` | 创建场景规则链 |
| `04-scene-trigger-filter.png` | 触发和过滤节点 |
| `05-change-originator.png` | 切换消息来源节点 |
| `06-rpc-config.png` | RPC 调用请求 配置 |
| `07-scene-success-failure.png` | 成功和失败分支 |
| `08-multi-condition.png` | 多条件读取其他设备遥测 |
| `09-scene-state.png` | 场景状态属性 |
| `10-rulechain-debug.png` | 规则链调试和事件 |
| `11-rpc-topics.png` | 目标设备 RPC 主题 |
| `12-mqtt-fallback.png` | 无 RPC 设备的 MQTT 联动 |
| `13-alarm-notification.png` | 场景失败告警和通知 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏设备名称、设备 ID、访问令牌和真实业务数据。
- 图片宽度建议 1200px 以上，保持清晰。
- 规则链截图尽量保留完整节点、关系和连接标签。
