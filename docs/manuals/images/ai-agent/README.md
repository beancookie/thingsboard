# AI Agent 截图清单

本目录存放 `AI Agent使用手册.md` 使用的截图。

建议按以下文件名补充：

| 文件名 | 页面/内容 |
| --- | --- |
| `01-assistant-button.png` | 页面右下角 AI 助手悬浮按钮 |
| `02-panel.png` | AI 助手对话面板 |
| `04-pending-actions.png` | 待确认操作 |
| `05-confirm-result.png` | 确认执行结果 |
| `06-tsl-upload.png` | 上传或粘贴 TSL |
| `07-clear-chat.png` | 清空对话 |
| `08-error.png` | 错误提示 |
| `09-query-tenants.png` | 查询租户 |
| `10-create-product.png` | 创建产品 |
| `11-create-device.png` | 创建设备 |
| `12-create-user.png` | 创建用户 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏邮箱、JWT、API 密钥、租户 ID和真实业务数据。
- 待确认操作截图要展示操作名称和参数，便于用户核对。
- 图片宽度建议 1200px 以上，保持清晰。
