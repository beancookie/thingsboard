# 计算字段截图清单

本目录存放 `计算字段使用手册.md` 使用的截图。

建议按以下文件名补充：

| 文件名 | 页面/内容 |
| --- | --- |
| `01-cf-menu.png` | 计算字段菜单入口 |
| `02-cf-list.png` | 计算字段列表 |
| `03-cf-filter.png` | 计算字段过滤条件 |
| `04-create-cf.png` | 创建计算字段 |
| `05-simple-config.png` | 简单计算字段配置 |
| `06-script-config.png` | 脚本计算字段配置 |
| `07-arguments.png` | 参数配置 |
| `08-output.png` | 输出配置 |
| `09-geofencing.png` | 地理围栏配置 |
| `10-propagation.png` | 传播配置 |
| `11-related-aggregation.png` | 关联实体聚合 |
| `12-entity-aggregation.png` | 时间序列数据聚合 |
| `13-test-script.png` | 测试脚本 |
| `14-debug.png` | 调试设置 |
| `15-events.png` | 计算字段事件 |
| `16-cf-details.png` | 计算字段详情 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏设备名称、设备 ID、表达式中的敏感参数。
- 图片宽度建议 1200px 以上，保持清晰。
- 配置截图要能看清参数名称、表达式和输出键。
