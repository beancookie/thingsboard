| `01-alarm-menu.png` | 告警菜单入口 |
| `02-alarm-list.png` | 告警列表 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏设备名称、客户名称、处理人邮箱和真实业务数据。
- 图片宽度建议 1200px 以上，保持清晰。
