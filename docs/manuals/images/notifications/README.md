# 通知手册截图清单

本目录存放 `告警与通知使用手册.md` 中通知部分的截图。

建议按以下文件名补充：

| 文件名 | 页面/内容 |
| --- | --- |
| `01-notification-bell.png` | 通知铃铛和未读数 |
| `02-inbox.png` | 通知收件箱 |
| `03-sent.png` | 已发送通知 |
| `04-send-notification.png` | 发送通知 |
| `05-recipients.png` | 收件人组列表 |
| `06-recipient-dialog.png` | 收件人组配置 |
| `07-templates.png` | 通知模板列表 |
| `08-template-dialog.png` | 通知模板配置 |
| `09-rules.png` | 通知规则列表 |
| `10-rule-dialog.png` | 通知规则配置 |
| `11-notification-settings.png` | 系统通知设置 |
| `12-user-notification-settings.png` | 个人通知设置 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏邮箱、手机号、Slack 令牌、Teams Webhook、真实客户数据。
- 图片宽度建议 1200px 以上，保持清晰。
