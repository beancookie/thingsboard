# 客户与用户手册截图清单

本目录存放 `客户与用户使用手册.md` 使用的截图。

建议按以下文件名补充：

| 文件名 | 页面/内容 |
| --- | --- |
| `01-customer-menu.png` | 客户菜单入口 |
| `02-customer-list.png` | 客户列表 |
| `03-create-customer.png` | 新增客户 |
| `04-customer-details.png` | 客户详情 |
| `05-customer-users.png` | 客户用户列表 |
| `06-add-customer-user.png` | 新增客户用户 |
| `07-activation-method.png` | 激活方式选择 |
| `08-activation-link.png` | 激活链接 |
| `09-user-details.png` | 用户详情 |
| `10-assign-resource.png` | 分配设备/资产给客户 |
| `11-public-vs-assigned.png` | 公开资源与客户资源 |
| `12-dashboard-settings.png` | 客户/用户仪表板配置 |

截图要求：

- 使用中文界面或统一英文界面，避免中英文混用。
- 隐藏或脱敏邮箱、电话、激活链接、密码和真实客户数据。
- 图片宽度建议 1200px 以上，保持清晰。
