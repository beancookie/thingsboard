# 资产管理使用手册

> 中国中铁物联网平台文档集
>
> 适用对象：平台租户管理员、产品/运维人员、第三方接入方

## 1. 文档说明

### 1.1 适用对象

- 平台租户管理员
- 产品、项目、运维人员
- 需要查看产品物模型资产的第三方接入方

### 1.2 权限要求

- 平台账号需要租户管理员权限。
- 客户用户只能看到分配给客户或公开的资产，通常为只读。
- 资产页面操作可以通过平台页面完成，也可以通过 REST API 完成。

### 1.3 资产与设备的区别

| 对象 | 是否真实连接 | 主要用途 |
| --- | --- | --- |
| 设备 | 是，通过 MQTT/HTTP 等接入 | 真实设备、网关 |
| 资产 | 否 | 业务对象、分组、产品元数据、站点/工点 |
| 实体视图 视图 | 否 | 设备或资产的视图 |

资产不会主动联网，也没有设备凭证和在线状态。资产的属性、遥测通常由规则链或 REST API 写入。

## 2. 资产的作用

### 2.1 业务对象建模

资产可以表示：

- 产品
- 站点、工点、项目
- 设备组、区域
- 客户资源
- 逻辑上的业务对象

资产可以关联设备和其他资产，用于构建层级关系，例如：

```text
站点资产 --Contains--> 设备
站点资产 --Contains--> 子站点资产
产品资产 --Manages--> 设备
```

### 2.2 产品资产

本平台在同步产品时会自动创建一个产品资产：

```text
名称：产品 <产品 ID>
类型：product
资产配置：租户默认资产配置
```

产品资产保存 TSL 和产品元数据，供产品详情、设备注册和排查使用。

### 2.3 客户与公开

资产可以：

- 分配给客户，客户用户登录后可见。
- 设为公开，所有客户可见。
- 取消分配或设为私有。

### 2.4 属性、遥测和告警

资产支持：

- 属性：`SERVER_SCOPE`、`SHARED_SCOPE`、`CLIENT_SCOPE`
- 最新遥测和历史遥测
- 告警和告警规则
- 计算字段
- 审计日志和版本控制

## 4. 资产配置

### 4.1 说明

每个资产必须绑定资产配置。资产配置定义资产的类型和默认行为。

平台同步产品时依赖租户默认资产配置。缺少默认配置时，产品同步会失败。

### 4.2 页面操作

1. 进入「资产配置」页面。
2. 查看已有资产配置。
3. 如需新建，点击「新增资产配置」。
4. 填写名称和类型。
5. 保存并记录资产配置 ID。

> 截图占位：`images/assets/03-asset-profile-list.png`
>
> 截图占位：`images/assets/04-create-asset-profile.png`

### 4.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/assetProfiles?pageSize=100&page=0` | 查询资产配置列表 |
| GET | `/api/assetProfile/{assetProfileId}` | 查询资产配置详情 |
| GET | `/api/assetProfileInfo/default` | 查询默认资产配置 |
| POST | `/api/assetProfile` | 创建资产配置 |

> 请求体字段以平台 Swagger 页面 `/swagger-ui.html` 为准。

## 5. 创建资产

### 5.1 页面操作

1. 进入「资产」页面。
2. 点击「新增资产」。
3. 填写资产名称，例如 `北京站点`。
4. 选择资产配置。
5. 可选：分配给客户。
6. 填写描述。
7. 点击保存。

> 截图占位：`images/assets/05-create-asset.png`

### 5.2 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 租户内唯一 |
| 标签 | 否 | 可读标签 |
| 资产配置 | 是 | 必填项 |
| 客户 | 否 | 分配给客户 |
| 描述 | 否 | 保存在 `additionalInfo.description` |

### 5.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/asset` | 创建资产 |
| GET | `/api/tenant/assets?pageSize=100&page=0` | 查询租户资产 |
| GET | `/api/tenant/assets?assetName={assetName}` | 按名称查询资产 |
| GET | `/api/asset/{assetId}` | 查询资产详情 |
| DELETE | `/api/asset/{assetId}` | 删除资产 |

### 6.1 页签说明

- 属性

- 告警规则

### 6.2 属性

1. 打开资产详情。
2. 进入「属性」页签。
3. 选择 `SERVER_SCOPE`、`SHARED_SCOPE` 或 `CLIENT_SCOPE`。

> 截图占位：`images/assets/07-asset-attributes.png`

API 地址：

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/plugins/telemetry/ASSET/{assetId}/values/attributes` | 查询资产属性 |
| POST | `/api/plugins/telemetry/ASSET/{assetId}/attributes/SERVER_SCOPE` | 写入服务端属性 |
| POST | `/api/plugins/telemetry/ASSET/{assetId}/attributes/SHARED_SCOPE` | 写入共享属性 |

### 6.3 遥测

资产遥测通常由规则链写入，也可以在资产详情「最新遥测」中查看。

| GET | `/api/plugins/telemetry/ASSET/{assetId}/values/timeseries` | 查询资产遥测 |

可以在资产上配置告警规则，查看资产告警。

API 地址：

| 方法 | 地址 | 用途 |

| GET | `/api/alarm/ASSET/{assetId}?pageSize=10&page=0` | 查询资产告警 |

## 7. 建立资产关系

### 7.1 关系类型

常用关系类型：

```text
Contains
Manages
```

示例：

```text
站点资产 --Contains--> 设备
站点资产 --Contains--> 子站点资产
产品资产 --Manages--> 设备
```

### 7.2 页面操作

1. 打开资产详情。
2. 进入「关系 / 关系」页签。
3. 点击「添加」。
4. 填写关系类型，例如 `Contains`。
5. 选择方向。
6. 选择目标设备或资产。
7. 保存。

> 截图占位：`images/assets/08-asset-relations.png`
>
> 截图占位：`images/assets/09-add-relation.png`

### 7.3 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/relation` | 创建关系 |
| GET | `/api/relations?fromId={assetId}&fromType=ASSET` | 查询资产关系 |
| DELETE | `/api/relation?fromId={assetId}&fromType=ASSET&relationType={type}&toId={targetId}&toType={targetType}` | 删除关系 |

## 8. 客户分配与公开

### 8.1 页面操作

**分配给客户**

1. 在资产列表选择资产。
2. 点击「分配给客户」。
3. 选择客户并保存。

**设为公开**

1. 在资产列表选择资产。
2. 点击「设为公开」。
3. 所有客户用户可见。

**取消分配 / 设为私有**

1. 在资产列表选择已分配资产。
2. 点击「取消分配」或「设为私有」。

> 截图占位：`images/assets/10-assign-customer.png`

### 8.2 API 地址

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/customer/{customerId}/asset/{assetId}` | 分配给客户 |
| DELETE | `/api/customer/asset/{assetId}` | 取消分配 |
| POST | `/api/customer/public/asset/{assetId}` | 设为公开 |

## 9. 本平台产品资产

### 9.1 自动创建

产品发布或同步时，平台会自动创建或更新：

```text
名称：产品 <产品 ID>
类型：product
资产配置：租户默认资产配置
```

### 9.2 属性

产品资产包含 `SERVER_SCOPE` 属性：

```text
product_id
category_id
tsl_version
property_count
event_count
action_count
tsl_json
tsl_schema
strict_unknown
```

### 9.3 使用场景

- 查看产品 TSL 和版本
- 查看属性、事件、行为数量
- 排查产品同步和设备注册问题
- 作为设备注册脚本获取 `tsl_schema` 的来源

> 截图占位：`images/assets/11-product-asset.png`
>
> 截图占位：`images/assets/12-product-asset-attributes.png`

### 9.4 注意事项

- 产品资产由平台自动管理，**不建议手工修改或删除**。
- 删除产品资产可能影响产品详情、设备注册和 TSL 校验。
- 修改产品请使用产品页面或产品同步接口。
- 删除产品前，平台会检查产品下是否存在设备。

## 10. 常见问题

| 问题 | 排查 |
| --- | --- |
| 产品同步失败，提示未配置默认资产模板 | 在 `/profiles/assetProfiles` 设置默认资产配置 |
| 资产列表为空 | 检查资产配置过滤条件 |
| 客户看不到资产 | 检查资产是否分配给客户或设为公开 |
| 资产没有遥测 | 资产不主动上报，需规则链或 REST 写入 |
| 产品资产属性异常 | 通过产品页面重新同步产品，不要手工改 |
| 删除资产失败 | 检查资产是否被关系、仪表板或规则链引用 |
| 资产名称冲突 | 资产名称在租户内唯一 |
