## 6.2 角色与路由

| 角色 | 产品菜单 | 产品页面 | 产品 API | 数据范围 |
| --- | --- | --- | --- | --- |
| 租户管理员 | 有 | 允许 | 允许 | JWT 对应租户 |
| 系统管理员 | 无 | 被 AuthGuard 拦截 | 403 | 无 |
| 客户用户 | 无 | 被拦截 | 403 | 无 |
| 未登录 | 无 | 跳登录 | 401 | 无 |

规则：

- 产品路由 `data.auth` 只配置租户管理员权限。
- `ProductController` 类级别限制租户管理员权限。
- `AdminController` 类级别限制系统管理员权限。
- 产品接口的 tenantId 始终来自 JWT，不接受跨租户查询。
- 请求体如果带其他 tenantId，返回 `403`。
- 跨租户产品详情返回 `404`，避免泄露产品是否存在。

## 6.3 产品列表

已实现：

- 关键字搜索，匹配 产品 ID 或产品名称。
- 表格列：产品 ID、名称、型号、分类、TSL 版本、状态、属性数、事件数、行为数、更新时间。
- 前端分页和排序。
- 新建产品后跳转产品详情。
- 操作列支持查看和删除，删除前二次确认。
- 不显示租户筛选器，也不显示 tenantId 列。

当前没有服务端分页、批量删除、批量同步。

## 6.4 产品详情

已实现：

- 展示产品基本信息、TSL 版本列表、属性/事件/行为目录。
- 查看属性原始定义、事件参数、行为输入/输出 JSON。
- 编辑物模型：修改 TSL 版本、JSON 内容和 `strictUnknown`。
- JSON 导入和本地 JSON 格式校验。
- 调用后端做 TSL 校验并展示逐条问题。
- 编辑物模型保存后自动同步中国中铁物联网平台，不再提供手动同步按钮。
- 同步失败时展示后端错误信息，重新保存同一版本可再次触发同步。
- “删除产品”按钮，确认成功后返回产品列表；有设备时展示后端冲突信息。
- 跳转到中国中铁物联网平台的设备配置、资产、规则链详情。

产品详情不读取 tenantId 查询参数，也不向前端暴露密码。

## 6.5 租户服务账号

入口有两个：

- 新建租户成功后自动打开初始化弹窗。
- 租户详情页点击“初始化厂商服务账号”。

弹窗行为：

```text
打开弹窗
  -> 自动调用 POST /api/thing-model/admin/tenants/{tenantId}/provision-auto
  -> 显示初始化中
  -> 成功显示服务账号 email
  -> 失败显示错误和重试按钮
```

用户不需要输入用户名或密码。密码不会返回前端。

手动兜底仍可使用 `/provision` 注册已有租户管理员，但正常流程优先使用自动初始化。

## 6.6 认证方式

前端直接复用浏览器已有的中国中铁物联网平台 JWT：

```http
X-Authorization: Bearer <TB_JWT>
```

`thing-model` 调用中国中铁物联网平台 `/api/auth/user` 校验 JWT，并缓存 60 秒。JWT 只用于身份校验和解析 tenantId/authority；写中国中铁物联网平台使用该租户自己的服务账号，不使用当前用户密码。

中国中铁物联网平台前端自己的 HTTP 拦截器会为 `/api/*` 添加 JWT。产品页面使用中国中铁物联网平台原生 `HttpClient` 配置，通过 `/api/thing-model` 前缀访问 `thing-model`。

## 6.7 开发与生产代理

开发环境 `ui-ngx/proxy.conf.js`：

```text
/api/thing-model/*  -> http://localhost:8090/api/*
/api/*              -> http://localhost:18080/api/*
/api/ws             -> ws://localhost:18080/api/ws
```

生产 Nginx 使用相同规则：

```nginx
location /api/thing-model/ {
    proxy_pass http://thing-model:8090/api/;
}

location /api/ {
    proxy_pass http://<tb-service>;
}
```

路径重写后，前端 `/api/thing-model/products` 对应 `thing-model` 的 `/api/products`。

## 6.8 菜单与国际化

- 产品菜单定义在 `ui-ngx/src/app/core/services/menu.models.ts`。
- 产品只出现在租户管理员的实体菜单分组中。
- 系统管理员菜单不包含产品。
- 产品、租户服务账号的中英文文案位于：
  - `ui-ngx/src/assets/locale/locale.constant-zh_CN.json`
  - `ui-ngx/src/assets/locale/locale.constant-en_US.json`

新增文案必须同时补齐中英文。

## 6.9 当前限制

- 没有独立的产品分页 API，列表一次返回当前租户全部产品。
- 没有发布、弃用、回滚按钮。
- 没有设备批量创建或凭证下载页面。
- 没有组织树、工点绑定、事件中心、遥测查询页面。
- 前端不直接调用中国中铁物联网平台的产品相关 API，统一走 `thing-model`。
